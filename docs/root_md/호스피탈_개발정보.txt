Rocky Linux에서 Apache + PHP 7.4와 PHP 8.x를 동시에 설치하고 도메인별로 다른 버전을 사용하는 방법입니다.

1. PHP 여러 버전 설치
bash
# Remi 저장소 추가 (Rocky Linux 9/10)
dnf install -y epel-release
dnf install -y https://rpms.remirepo.net/enterprise/remi-release-9.rpm

# PHP 7.4 설치
dnf module reset php
dnf module enable php:remi-7.4 -y
dnf install -y php74-php php74-php-fpm php74-php-cli php74-php-common php74-php-mysqlnd

# PHP 8.3 설치 (또는 8.1, 8.2)
dnf install -y php83-php php83-php-fpm php83-php-cli php83-php-common php83-php-mysqlnd

# 또는 PHP 8.2
dnf install -y php82-php php82-php-fpm php82-php-cli php82-php-common php82-php-mysqlnd
2. PHP-FPM 설정 (각 버전별)
bash
# PHP 7.4 FPM 설정
vi /etc/opt/remi/php74/php-fpm.d/www.conf
포트를 다르게 설정:

ini
; PHP 7.4
listen = 127.0.0.1:9074

; 또는 소켓 방식
listen = /var/opt/remi/php74/run/php-fpm/php74-fpm.sock
bash
# PHP 8.3 FPM 설정
vi /etc/opt/remi/php83/php-fpm.d/www.conf
ini
; PHP 8.3
listen = 127.0.0.1:9083

; 또는 소켓 방식
listen = /var/opt/remi/php83/run/php-fpm/php83-fpm.sock
3. PHP-FPM 서비스 시작
bash
# PHP 7.4 FPM
systemctl enable php74-php-fpm
systemctl start php74-php-fpm

# PHP 8.3 FPM
systemctl enable php83-php-fpm
systemctl start php83-php-fpm

# 상태 확인
systemctl status php74-php-fpm
systemctl status php83-php-fpm
4. Apache VirtualHost 설정
방법 1: ProxyPassMatch 사용 (권장)
bash
# Apache에 proxy 모듈 활성화
dnf install -y mod_proxy_fcgi
PHP 7.4를 사용하는 도메인:

apache
<VirtualHost *:80>
    ServerName domain1.com
    DocumentRoot /var/www/domain1
    
    <Directory /var/www/domain1>
        AllowOverride All
        Require all granted
    </Directory>
    
    # PHP 7.4 사용
    <FilesMatch \.php$>
        SetHandler "proxy:fcgi://127.0.0.1:9074"
    </FilesMatch>
    
    # 또는 소켓 방식
    # <FilesMatch \.php$>
    #     SetHandler "proxy:unix:/var/opt/remi/php74/run/php-fpm/php74-fpm.sock|fcgi://localhost"
    # </FilesMatch>
</VirtualHost>
PHP 8.3을 사용하는 도메인:

apache
<VirtualHost *:80>
    ServerName domain2.com
    DocumentRoot /var/www/domain2
    
    <Directory /var/www/domain2>
        AllowOverride All
        Require all granted
    </Directory>
    
    # PHP 8.3 사용
    <FilesMatch \.php$>
        SetHandler "proxy:fcgi://127.0.0.1:9083"
    </FilesMatch>
</VirtualHost>
방법 2: FastCGI 직접 설정
apache
<VirtualHost *:80>
    ServerName domain1.com
    DocumentRoot /var/www/domain1
    
    # PHP 7.4
    <IfModule mod_fastcgi.c>
        AddHandler php74-fcgi .php
        Action php74-fcgi /php74-fcgi
        Alias /php74-fcgi /usr/lib/cgi-bin/php74-fcgi
        FastCgiExternalServer /usr/lib/cgi-bin/php74-fcgi -socket /var/opt/remi/php74/run/php-fpm/php74-fpm.sock -pass-header Authorization
    </IfModule>
</VirtualHost>
5. Apache 재시작
bash
# 설정 테스트
httpd -t

# Apache 재시작
systemctl restart httpd
6. 확인 방법
각 도메인의 DocumentRoot에 info.php 생성:

php
<?php
phpinfo();
?>
브라우저에서 http://domain1.com/info.php와 http://domain2.com/info.php를 열어서 PHP 버전 확인

7. 문제 해결
bash
# PHP-FPM 로그 확인
tail -f /var/opt/remi/php74/log/php-fpm/error.log
tail -f /var/opt/remi/php83/log/php-fpm/error.log

# Apache 로그 확인
tail -f /var/log/httpd/error_log

# 포트 리스닝 확인
netstat -tlnp | grep php-fpm
# 또는
ss -tlnp | grep php-fpm

# Rocky Linux Android Studio 설치 및 원격 ADB 디버깅 환경 구성

## 목표
Rocky Linux 서버에 Android Studio를 설치하고, Tailscale VPN을 통해 원격지의 안드로이드 폰과 무선 디버깅이 가능하도록 전체 환경을 구성한다.

## 현재 환경
- OS: Rocky Linux (GUI 데스크톱 환경 이미 구성됨)
- 용도: Android 앱 개발 및 원격 무선 디버깅

## 설치할 Android Studio 버전
- Android Studio Narwhal 3 Feature Drop | 2025.1.3
- Build #AI-251.26094.121.2513.14007798
- Runtime: JDK 21

## 작업 2: Android Studio 설치

### 2-1. Android Studio 다운로드
```bash
cd /tmp
# 최신 Android Studio Narwhal 다운로드 (공식 다운로드 페이지에서 최신 링크 확인)
wget https://redirector.gvt1.com/edgedl/android/studio/ide-zips/2025.1.3.13/android-studio-2025.1.3.13-linux.tar.gz
```

### 2-2. 설치
```bash
sudo tar -xzf android-studio-2025.1.3.13-linux.tar.gz -C /opt/
sudo chown -R $USER:$USER /opt/android-studio
```

### 2-3. 심볼릭 링크 및 PATH 설정
```bash
sudo ln -sf /opt/android-studio/bin/studio.sh /usr/local/bin/android-studio

# PATH에 Android SDK 도구 추가
cat >> ~/.bashrc << 'EOF'

# Android SDK
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin
EOF
source ~/.bashrc
```

### 2-4. 데스크톱 메뉴 엔트리 생성
```bash
mkdir -p ~/.local/share/applications
cat > ~/.local/share/applications/android-studio.desktop << 'EOF'
[Desktop Entry]
Version=1.0
Type=Application
Name=Android Studio
Comment=Android Development IDE
Icon=/opt/android-studio/bin/studio.svg
Exec=/opt/android-studio/bin/studio.sh %f
Categories=Development;IDE;
Terminal=false
StartupNotify=true
StartupWMClass=jetbrains-studio
EOF
```

### 2-5. Android Studio 초기 실행 및 SDK 설치
```bash
# GUI에서 실행하거나
android-studio

# 초기 설정 마법사에서:
# - Standard 설치 선택
# - Android SDK 설치 (기본 위치: ~/Android/Sdk)
# - 필요한 SDK 플랫폼 선택 (Android 14, 13 등)
# - Intel HAXM 또는 KVM 에뮬레이터 가속 설정
```

## 작업 3: ADB 및 플랫폼 도구 설정

### 3-1. ADB 설치 확인
```bash
# Android Studio SDK 설치 후 자동으로 설치됨
# 위치: ~/Android/Sdk/platform-tools/adb

adb version
```

### 3-2. udev 규칙 설정 (USB 디버깅용, 선택사항)
```bash
sudo cat > /etc/udev/rules.d/51-android.rules << 'EOF'
# Samsung
SUBSYSTEM=="usb", ATTR{idVendor}=="04e8", MODE="0666", GROUP="plugdev"
# Google
SUBSYSTEM=="usb", ATTR{idVendor}=="18d1", MODE="0666", GROUP="plugdev"
# 기타 제조사 추가 가능
EOF
sudo chmod a+r /etc/udev/rules.d/51-android.rules
sudo udevadm control --reload-rules
```

## 작업 4: Tailscale VPN 설치 (원격 디버깅용)

### 4-1. Tailscale 설치
```bash
curl -fsSL https://tailscale.com/install.sh | sh
```

### 4-2. Tailscale 시작 및 로그인
```bash
sudo systemctl enable --now tailscaled
sudo tailscale up

```

### 4-3. Tailscale 상태 확인
```bash
tailscale status
# 연결된 기기 목록과 IP 주소 확인
```

## 작업 5: 원격 안드로이드 폰 ADB 연결

### 5-1. 안드로이드 폰 사전 설정 (폰에서 수행)
1. 설정 → 개발자 옵션 활성화
2. 개발자 옵션 → USB 디버깅 ON
3. 개발자 옵션 → 무선 디버깅 ON
4. 무선 디버깅 → IP 주소 및 포트 확인 (예: 192.168.x.x:42107)
5. Tailscale 앱 설치 및 동일 계정 로그인
6. Tailscale 앱에서 VPN 연결 ON

### 5-2. 서버에서 폰의 Tailscale IP 확인
```bash
tailscale status
# 예시 출력:
# 100.100.100.1   rocky-server    linux   -
# 100.100.100.2   galaxy-buddy3   android active; direct ...
```

### 5-3. ADB로 폰에 연결
```bash
# 폰의 Tailscale IP와 무선 디버깅 포트 사용
adb connect 100.x.x.x:42107

# 연결 확인
adb devices
```

### 5-4. Android Studio에서 기기 인식
- Android Studio 실행

```bash
# 3. Tailscale 설치
curl -fsSL https://tailscale.com/install.sh | sh

sudo tailscale up

/opt/android-studio/bin/studio.sh
```
