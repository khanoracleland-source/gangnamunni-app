## 🛠️ 관리자 페이지 CRUD 패턴 (기존 코드 분석)

### 공통 구조 (admin_categories.php 기준)
```php
<?php
session_start();
require_once __DIR__ . '/../dbconfig.php';
require_once __DIR__ . '/theme_helper.php';

// 1. DB 연결
$connect = mysqli_connect(G5_MYSQL_HOST, G5_MYSQL_USER, G5_MYSQL_PASSWORD, G5_MYSQL_DB, G5_MYSQL_PORT);
mysqli_set_charset($connect, 'utf8mb4');

// 2. 로그인 체크
$is_logged_in = isset($_SESSION['ad_admin_logged_in']) && $_SESSION['ad_admin_logged_in'] === true;

// 3. 로그인 처리
if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_POST['login'])) {
    if ($username === 'admin' && $password === 'admin123') {
        $_SESSION['ad_admin_logged_in'] = true;
        header('Location: admin_categories.php');
        exit;
    }
}

// 4. CRUD 작업
// CREATE
if ($_POST['add_category'] && $is_logged_in) {
    mysqli_query($connect, "INSERT INTO gangnamunni_categories ...");
}

// UPDATE
if ($_POST['edit_category'] && $is_logged_in) {
    mysqli_query($connect, "UPDATE gangnamunni_categories SET ... WHERE id = {$id}");
}

// DELETE
if ($_GET['delete'] && $is_logged_in) {
    mysqli_query($connect, "DELETE FROM gangnamunni_categories WHERE id = {$id}");
}

// TOGGLE (활성화/비활성화)
if ($_GET['toggle'] && $is_logged_in) {
    mysqli_query($connect, "UPDATE gangnamunni_categories SET is_active = 1 - is_active WHERE id = {$id}");
}

// 5. 목록 조회
$result = mysqli_query($connect, "SELECT * FROM gangnamunni_categories ORDER BY display_order");

// 6. HTML 출력 (테이블 + 폼)
?>
<!DOCTYPE html>
<html>
<head>...</head>
<body>
    <!-- 로그인 폼 또는 관리 화면 -->
    <table class="categories-table">
        <!-- 목록 표시 -->
    </table>
    <form method="POST">
        <!-- 추가 폼 -->
    </form>
</body>
</html>
```

### 재사용 가능한 요소
1. **로그인 체크**: 모든 페이지 동일 (`$_SESSION['ad_admin_logged_in']`)
2. **CRUD 패턴**: INSERT, UPDATE, DELETE, SELECT
3. **HTML 구조**: 헤더 + 테이블 + 폼
4. **스타일**: 공통 CSS (테마 적용)
