## 수정된 주요 문제들

### 1. PHP 8 문법 오류 (Parse Errors)

#### 1.1 배열 접근 문법 - 문자열 내부
**문제**: PHP 8에서 double-quoted string 내부의 배열 접근 시 curly braces 필요
```php
// ❌ 오류 (PHP 8)
"$nfor['path']/config.php"
"charset=$nfor['charset']"

// ✅ 수정
"{$nfor['path']}/config.php"
"charset={$nfor['charset']}"
```
**영향 받은 파일**:
- function.lib.php (다수)
- shop.lib.php (다수)
- api.lib.php
- html_head.php
- 기타 908개 파일

#### 1.2 Short Echo Tag 내부의 Curly Braces
**문제**: `<?=` 태그 내부에서는 curly braces 불필요
```php
// ❌ 오류
<?={$nfor['path']}?>

// ✅ 수정
<?=$nfor['path']?>
```
**영향 받은 파일**: 288개 PHP 파일 (전체 skin, admin 디렉토리)

#### 1.3 함수 호출 시 Curly Braces 오류
**문제**: 함수 인자에 curly braces 사용 불가
```php
// ❌ 오류
basename({$_SERVER['PHP_SELF']})

// ✅ 수정
basename($_SERVER['PHP_SELF'])
```
**영향 받은 파일**: path.php, shop.lib.php (46개 수정)

#### 1.4 JavaScript 함수 호출 내부의 중첩 따옴표
**문제**: double-quoted string 내부의 중첩된 single quotes
```php
// ❌ 오류
"<a href=\"javascript:member('$row['st_insert_id']')\">"

// ✅ 수정 (문자열 연결 사용)
"<a href=\"javascript:member('" . $row['st_insert_id'] . "')\">"
```
**영향 받은 파일**: shop.lib.php (5개 함수)

#### 1.5 PHPMailer __autoload() 제거
**문제**: PHP 8에서 `__autoload()` 함수 제거됨
```php
// ❌ 오류
function __autoload($classname) {
    PHPMailerAutoload($classname);
}

// ✅ 수정
spl_autoload_register(function($classname) {
    PHPMailerAutoload($classname);
});
```
**영향 받은 파일**: PHPMailer/PHPMailerAutoload.php

### 2. PHP 8 경고 및 Deprecated (Warnings)

#### 2.1 Undefined Array Key
**문제**: 배열 키 존재 확인 없이 접근 시 경고
```php
// ❌ 경고 발생
if($_GET['path']) { ... }
if($nfor['url']) { ... }

// ✅ 수정
if(isset($_GET['path'])) { ... }
if(!isset($nfor['url']) || !$nfor['url']) { ... }
```
**수정된 위치**: nfor.php (다수), config.php

#### 2.2 Deprecated 변수
**문제**: `$HTTP_SERVER_VARS`, `$HTTP_POST_VARS` 등 제거됨
```php
// ❌ Deprecated
$HTTP_SERVER_VARS

// ✅ 수정
$_SERVER
```
**수정된 파일**: nfor.php

#### 2.3 Null Parameter Deprecation
**문제**: preg_replace()에 null 전달 시 deprecated
```php
// ❌ Deprecated
preg_replace("/[^0-9]*/s", "", $str);

// ✅ 수정
preg_replace("/[^0-9]*/s", "", $str ?? '');
```
**수정된 파일**: function.lib.php (line 1132)

## 주의사항

### 1. 에러 리포팅 설정
현재 에러 리포팅이 다음과 같이 설정됨:
```php
// nfor.php
error_reporting(E_ERROR | E_PARSE);
```
- Warning은 숨김 처리 (프로덕션 환경에 적합)
- Fatal Error와 Parse Error만 표시

### 2. 남은 경고들
일부 경고들이 여전히 존재하나 기능에 영향 없음:
- Undefined variables (초기화 전 사용)
- Trying to access array offset on null
- Deprecated dirname() with null

이러한 경고들은 코드 품질 개선 시 점진적으로 수정 권장

### 3. CORS 이슈
폰트 로딩 시 CORS 오류 발생:
```
Access to font at 'https://hairwang.com/rb/splash.php' blocked
```
- 폰트 파일이 외부 사이트로 리다이렉트되는 문제
- 로컬 폰트 파일 사용으로 변경 권장
