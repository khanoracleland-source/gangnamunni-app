| 제공자 | OAuth 버전 | 지원 기능 |
|--------|-----------|----------|
| **네이버** | OAuth 2.0 | 프로필, 이메일, 이름 |

| **구글** | OAuth 2.0 | 프로필, 이메일, 이름 |
| **페이스북** | OAuth 2.0 | 프로필, 이메일 |
| **트위터** | OAuth 2.0 | 프로필, 이메일 |
| **페이코** | OAuth 2.0 | 프로필, 이메일, 이름 |

### 2.3 API 엔드포인트

#### SNS 로그인 API
```
POST /api/sns/login.php
```
- **기능**: SNS 토큰으로 로그인 처리
- **파라미터**:
  - `provider`: SNS 제공자 (naver, kakao, google, facebook, twitter, payco)
  - `token`: SNS Access Token
  - `auto_register`: 자동 회원가입 여부 (true/false)
  - `custom_fields`: 커스텀 필드 (JSON)
- **응답**: 사용자 정보 또는 에러 메시지

#### JWT 토큰 API
```
POST /api/sns/token.php
```
- **기능**: JWT 토큰 발급/갱신/검증
- **액션**:
  - `issue`: 토큰 발급
  - `refresh`: 토큰 갱신
  - `verify`: 토큰 검증

#### 콜백 API
```
POST /api/sns/callback.php
```
- **기능**: SNS OAuth 콜백 처리
- **파라미터**: SNS별 콜백 파라미터

### 2.4 인증 방식

#### API 키 기반 인증
```bash
# HTTP 헤더 방식 (권장)
curl -X POST "https://domain.com/api/sns/login.php" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "X-API-Secret: YOUR_API_SECRET" \
  -d "provider=naver&token=ACCESS_TOKEN"

# 파라미터 방식
curl -X POST "https://domain.com/api/sns/login.php" \
  -d "api_key=YOUR_API_KEY" \
  -d "api_secret=YOUR_API_SECRET" \
  -d "provider=naver&token=ACCESS_TOKEN"
```

#### IP 화이트리스트
- API 키별로 허용 IP 설정
- CIDR 표기법 지원 (예: 192.168.1.0/24)
- 관리자 페이지에서 관리

### 2.5 주요 기능

✅ **자동 회원 가입**

- 중복 가입 방지 (SNS ID 기반)
