## 📋 작업 개요

**목적:** 이미지가 표시되지 않는 문제 해결
**방법:** media 테이블의 disk 컬럼 데이터 수정

**문제 원인:**
- media 테이블의 disk = 'media' → 파일 경로: `public/media/{id}/파일명`
- 실제 파일 위치: `storage/app/public/{id}/파일명` (웹 접근: `public/storage/{id}/파일명`)
- Laravel filesystems.php 설정상 disk='public' 사용해야 함

## 📁 파일 경로 구조

### Laravel Filesystems 설정 (config/filesystems.php)

```php
'disks' => [
    'public' => [
        'driver' => 'local',
        'root' => storage_path('app/public'),
        'url' => env('APP_URL').'/storage',
        'visibility' => 'public',
    ],

    'media' => [
        'driver' => 'local',
        'root' => public_path('media'),
        'url' => env('APP_URL').'/media',
    ],
]
```

### 변경 후 경로 매핑

**DB disk='public' 설정:**
```
저장 위치: storage/app/public/{model_id}/{file_name}
웹 접근: {APP_URL}/storage/{model_id}/{file_name}
```

**예시:**
```
DB: disk='public', model_id=1, file_name='image.png'
실제 파일: storage/app/public/1/image.png
웹 URL: https://frezka.seoulbeauty.app/storage/1/image.png
```

## 🔍 기술 참고

### Laravel Spatie Media Library

이 프로젝트는 [Spatie Media Library](https://spatie.be/docs/laravel-medialibrary) 사용:
- Polymorphic relationships로 다양한 모델에 미디어 첨부
- `media` 테이블의 `disk` 컬럼으로 저장소 지정
- `model_type`, `model_id`로 소유자 모델 참조

### Polymorphic Relationship 예시

```php
// Branch 모델
class Branch extends Model {
    use HasMediaTrait;

    public function registerMediaCollections(): void {
        $this->addMediaCollection('feature_image')
             ->disk('public'); // disk 설정
    }
}

// Slider 모델
class Slider extends Model {
    use HasMediaTrait;

    public function registerMediaCollections(): void {
        $this->addMediaCollection('feature_image')
             ->disk('public'); // disk 설정
    }
}
```
