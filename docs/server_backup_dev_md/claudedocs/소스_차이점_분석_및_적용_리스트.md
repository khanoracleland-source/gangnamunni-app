## 📝 참고사항

### 이미지가 안 보이는 이유 (해결됨)
1. **주 원인:** `public/storage` 심볼릭 링크 없음
2. **부 원인:** 서버 DB 연결로 인한 느린 속도 및 네트워크 의존성
3. **해결책:**
   - `php artisan storage:link` 실행
   - 로컬 DB로 변경 (`server2_frezka`)

### Laravel Storage 구조
```
storage/app/public/        ← 실제 파일 저장 위치
         ↑
         | (심볼릭 링크)
         ↓
public/storage/            ← 웹에서 접근하는 경로
```

### 이미지 URL 예시
- 저장 위치: `storage/app/public/1/image.jpg`
- 웹 접근: `https://frezka.seoulbeauty.app/storage/1/image.jpg`
