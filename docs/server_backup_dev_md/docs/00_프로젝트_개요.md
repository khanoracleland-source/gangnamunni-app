## 📞 문제 해결 빠른 참조

### 403 Forbidden 에러
```apache
# httpd-vhosts.conf 확인
<Directory "경로">
    Require all granted
    AllowOverride All
</Directory>
```
Apache 재시작 필요

### 500 Internal Server Error (Laravel)
```bash
# 권한 설정
icacls "프로젝트경로\storage" /grant Everyone:(OI)(CI)F /T
icacls "프로젝트경로\bootstrap\cache" /grant Everyone:(OI)(CI)F /T

# 캐시 클리어
php artisan config:clear
php artisan cache:clear
```

### DB 연결 실패
```env
# .env 파일 확인
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=데이터베이스명
DB_USERNAME=root
DB_PASSWORD=<REMOVED_DB_PASSWORD>
```

### 도메인 접근 불가
```
# Windows hosts 파일 확인 (관리자 권한 필요)
C:\Windows\System32\drivers\etc\hosts

# 추가 확인
```
