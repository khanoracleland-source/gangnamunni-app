## 1단계: Windows hosts 파일 설정

### 파일 위치
```
C:\Windows\System32\drivers\etc\hosts
```

### 설정 방법

#### A. 관리자 권한으로 메모장 열기
1. 시작 메뉴 → "메모장" 검색
2. 우클릭 → **관리자 권한으로 실행**
3. 파일 → 열기 → 주소창에 `C:\Windows\System32\drivers\etc` 입력
4. 파일 형식을 **"모든 파일 (*.*)"**로 변경
5. `hosts` 파일 선택

#### B. 추가할 내용
```
# ============================================================
# CareBaby 프로젝트 로컬 도메인 (2025-01-09)
# ============================================================
127.0.0.1 paikpc.seoulbeauty.local
127.0.0.1 vps20-2-dashboard.seoulbeauty.local
127.0.0.1 frezka.seoulbeauty.local
127.0.0.1 kivicare.seoulbeauty.local
127.0.0.1 carebaby.seoulbeauty.local
```

#### C. 저장 및 확인
```cmd
# 명령 프롬프트에서 확인
ping vps20-2-dashboard.seoulbeauty.local

# 예상 결과:
# Reply from 127.0.0.1: bytes=32 time<1ms TTL=128
```

## 3단계: Apache 재시작

### XAMPP Control Panel 사용
1. XAMPP Control Panel 실행
2. Apache **"Stop"** 버튼 클릭
3. Apache **"Start"** 버튼 클릭

### 명령어로 재시작 (선택사항)
```cmd
cd C:\xampp\apache\bin
httpd.exe -k restart
```

### 설정 문법 확인
```cmd
cd C:\xampp\apache\bin
httpd.exe -t
```

## 문제 해결

### 1. 로컬: 403 Forbidden

**원인**: Apache 권한 설정 문제

**해결**:
```apache
# httpd-vhosts.conf 확인
<Directory "경로">
    Require all granted  ← 이 줄 필수
    AllowOverride All
</Directory>
```
Apache 재시작 필요

---

### 2. 로컬: 도메인 접근 불가 (This site can't be reached)

**원인**: hosts 파일 설정 누락 또는 Apache 미재시작

**해결**:
```cmd
# 1. hosts 파일 확인
notepad C:\Windows\System32\drivers\etc\hosts

# 2. ping 테스트
ping vps20-2-dashboard.seoulbeauty.local

# 3. Apache 재시작
# XAMPP Control Panel에서 Apache Stop → Start
```

---

### 3. 로컬: Laravel 500 Internal Server Error

**원인**: storage 폴더 권한 문제

**해결** (관리자 권한 cmd):
```cmd
icacls "H:\carebaby_project\server_backup_dev\frezka_admin_panel_v4.0.3\storage" /grant Everyone:(OI)(CI)F /T
icacls "H:\carebaby_project\server_backup_dev\frezka_admin_panel_v4.0.3\bootstrap\cache" /grant Everyone:(OI)(CI)F /T
```

또는 Laravel 캐시 클리어:
```bash
cd H:\carebaby_project\server_backup_dev\frezka_admin_panel_v4.0.3
php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear
```

---

### 4. 서버: SSL 인증서 갱신

**Cloudflare Proxied 사용 시**: 자동 SSL (추가 작업 불필요)

**Let's Encrypt 직접 사용 시**:
```bash
# 인증서 갱신
sudo certbot renew

# Apache 재시작
sudo systemctl restart httpd
```

---

### 5. 서버: SELinux 권한 문제

**현상**: 403 Forbidden 또는 Permission Denied

**해결**:
```bash
# SELinux 컨텍스트 설정
sudo chcon -R -t httpd_sys_rw_content_t /home/carebaby/server_backup_dev/frezka_admin_panel_v4.0.3/storage
sudo chcon -R -t httpd_sys_rw_content_t /home/carebaby/server_backup_dev/kivicare-laravel-web-v1.9.0/storage

# 또는 SELinux 일시 비활성화 (테스트 목적)
sudo setenforce 0

# 영구 비활성화 (권장하지 않음)
sudo vi /etc/selinux/config
# SELINUX=disabled
```
