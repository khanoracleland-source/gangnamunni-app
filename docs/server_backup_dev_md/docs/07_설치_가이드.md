### Frezka 설치 시 발생한 이슈 및 해결

#### 이슈 1: Maximum execution time exceeded

**원인**: PHP 실행 시간 제한 (120초) 초과

**해결**:
```ini
# C:\xampp\php\php.ini 수정
max_execution_time = 600
memory_limit = 512M
```
Apache 재시작 필요

---

#### 이슈 2: Permission denied (storage 폴더)

**원인**: Laravel storage 폴더 쓰기 권한 없음

**해결** (관리자 권한 cmd):
```cmd
icacls "H:\carebaby_project\server_backup_dev\frezka_admin_panel_v4.0.3\storage" /grant Users:(OI)(CI)F /T

# 또는 캐시 폴더만
rd /S /Q "H:\carebaby_project\server_backup_dev\frezka_admin_panel_v4.0.3\storage\framework\cache"
mkdir "H:\carebaby_project\server_backup_dev\frezka_admin_panel_v4.0.3\storage\framework\cache"
mkdir "H:\carebaby_project\server_backup_dev\frezka_admin_panel_v4.0.3\storage\framework\cache\data"
```

---

#### 이슈 3: 419 Page Expired (CSRF 토큰 만료)

**원인**: Laravel 세션 문제

**해결**:
```cmd
# 캐시 및 세션 완전 삭제
rd /S /Q "storage\framework\cache"
rd /S /Q "storage\framework\sessions"
rd /S /Q "storage\framework\views"

# 재생성
mkdir "storage\framework\cache"
mkdir "storage\framework\cache\data"
mkdir "storage\framework\sessions"
mkdir "storage\framework\views"
```

브라우저 캐시 삭제 (Ctrl + Shift + Delete) 후 재접속

### KiviCare 설치 시 발생한 이슈 및 해결

#### 이슈 1: DB 비밀번호 불일치

**에러**:
```
SQLSTATE[HY000] [1045] Access denied for user 'root'@'localhost'
```

**원인**: `.env` 파일의 DB_PASSWORD가 `root`로 설정됨

**해결**:
```env
# .env 파일 수정
DB_PASSWORD=<REMOVED_DB_PASSWORD>
```

Laravel 캐시 클리어:
```bash
php artisan config:clear
```

---

#### 이슈 2: PHP 8.2 Strict Typing 경고

**경고**:
```
Warning: "resource" is not a supported builtin type
Warning: "integer" will be interpreted as a class name
```

**원인**: vendor 라이브러리의 PHP 8.2 호환성 이슈

**해결**: **무시 가능** (기능에 영향 없음)

또는 워닝 숨기기:
```env
# .env 파일에 추가
APP_DEBUG=false
```

---

#### 이슈 3: storage 폴더 권한 문제

**에러**:
```
file_put_contents(...): Failed to open stream: Permission denied
```

**해결** (관리자 권한 cmd):
```cmd
icacls "H:\carebaby_project\server_backup_dev\kivicare-laravel-web-v1.9.0\storage" /grant Everyone:(OI)(CI)F /T
icacls "H:\carebaby_project\server_backup_dev\kivicare-laravel-web-v1.9.0\bootstrap\cache" /grant Everyone:(OI)(CI)F /T
```

## 문제 해결

### 1. 로그인 실패 (419 Page Expired)

**원인**: CSRF 토큰 만료 또는 세션 문제

**해결**:
```bash
# Laravel 캐시 클리어
php artisan config:clear
php artisan cache:clear
php artisan session:table
```

브라우저 캐시 삭제:
- Ctrl + Shift + Delete
- 쿠키 및 사이트 데이터 삭제
- 캐시된 이미지 및 파일 삭제

시크릿 모드로 재접속:
- Chrome: Ctrl + Shift + N
- Firefox: Ctrl + Shift + P

---

### 2. 500 Internal Server Error

**원인**: Laravel 설정 또는 권한 문제

**해결 순서**:

#### A. 캐시 클리어
```bash
php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear
```

#### B. 권한 설정
```cmd
# Windows
icacls "프로젝트경로\storage" /grant Everyone:(OI)(CI)F /T
icacls "프로젝트경로\bootstrap\cache" /grant Everyone:(OI)(CI)F /T
```

#### C. .env 파일 확인
```env
APP_DEBUG=true  ← 디버그 모드 활성화 (에러 상세 확인)
DB_HOST=127.0.0.1
DB_PASSWORD=<REMOVED_DB_PASSWORD>  ← 올바른 비밀번호
```

#### D. 로그 파일 확인
```
Laravel 로그: storage/logs/laravel.log
Apache 로그: C:\xampp\apache\logs\프로젝트명-error.log
```

---

### 3. DB 연결 실패

**에러**:
```
SQLSTATE[HY000] [2002] Connection refused
SQLSTATE[HY000] [1045] Access denied
```

**해결**:

#### A. XAMPP MySQL 실행 확인
```
XAMPP Control Panel → MySQL → Start
```

#### B. .env 파일 확인
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1  ← localhost 아님
DB_PORT=3306
DB_DATABASE=데이터베이스명
DB_USERNAME=root
DB_PASSWORD=<REMOVED_DB_PASSWORD>
```

#### C. 데이터베이스 존재 확인
```
phpMyAdmin → 데이터베이스 목록 확인
```

---

### 4. 한국어 표시 안됨 (Frezka)

**원인**: 언어 설정 미변경

**해결**:
```
관리자 로그인 → Settings → General → Language → Korean 선택
```

또는 `.env` 파일 수정:
```env
APP_LOCALE=ko
APP_FALLBACK_LOCALE=ko
```

---

### 5. NPM 빌드 실패

**에러**:
```
npm ERR! code ELIFECYCLE
npm ERR! errno 1
```

**해결**:

#### A. Node.js 버전 확인
```bash
node --version
# 16.x 이상 필요
```

#### B. 패키지 재설치
```bash
rm -rf node_modules package-lock.json
npm install
npm run prod
```

#### C. 메모리 부족 시
```bash
# Windows
set NODE_OPTIONS=--max_old_space_size=4096
npm run prod

# Linux/Mac
NODE_OPTIONS=--max_old_space_size=4096 npm run prod
```

---

### 6. 이미지 업로드 실패

**원인**: storage 폴더 권한 또는 심볼릭 링크 문제

**해결**:

#### A. 심볼릭 링크 생성
```bash
php artisan storage:link
```

#### B. 권한 설정
```cmd
icacls "프로젝트경로\storage" /grant Everyone:(OI)(CI)F /T
icacls "프로젝트경로\public\storage" /grant Everyone:(OI)(CI)F /T
```

#### C. .env 파일 확인
```env
FILESYSTEM_DISK=public
```
