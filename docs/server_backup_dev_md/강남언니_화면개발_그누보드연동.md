## 🔧 3. 그누보드 SNS/결제 모듈 분석

### 3.1 그누보드 소셜로그인 (SNS)

#### 지원 현황

**그누보드 5.3+ 기본 지원** ✅:
- 네이버 (Naver)
- 카카오 (Kakao)
- 구글 (Google)
- 페이스북 (Facebook)

**출처**: [그누보드5 매뉴얼 - SNS(소셜로그인)](https://sir.kr/manual/g5/276)

#### 설정 방법

**1. 관리자 환경설정**:
```
관리자 > 기본환경설정 > SNS 소셜로그인

네이버:
- Client ID 입력
- Client Secret 입력

카카오:
- REST API 키 입력
```

**2. 플러그인 사용 (5.3 이전 버전)**:
- **다운로드**: [그누보드5 소셜로그인 v2](https://sir.kr/g5_plugin/2213)
- **설치 가이드**: [설치방법](https://gnustudy.com/bbs/board.php?bo_table=gnu_tip&wr_id=66)

#### API 인증 방식

**그누보드 소셜로그인 흐름**:
```
1. 사용자가 "카카오 로그인" 버튼 클릭
2. 카카오 로그인 페이지로 리다이렉트
3. 사용자 인증 후 Authorization Code 반환
4. 그누보드가 Access Token 요청
5. 사용자 정보 (이메일, 이름) 조회
6. 그누보드 회원 가입 또는 로그인 처리
```

### 3.2 그누보드 결제 모듈

#### 포트원 (PortOne / 구 아임포트)

**지원 PG사** ✅:
- **KG이니시스** (html5_inicis, inicis)
- **토스페이먼츠** (uplus)
- **NHN KCP** (kcp)
- **나이스페이** (nice)
- 기타 10+ PG사

**출처**:
- [KG 이니시스 | PortOne Docs](https://portone.gitbook.io/docs/pg/payment-gateway/inicis)
- [GitHub - iamport/iamport-manual](https://github.com/iamport/iamport-manual)

#### 연동 방법

**1. 포트원 가맹점 신청**:
```
1. https://portone.io 접속
2. 회원가입 및 가맹점 등록
3. 상점 식별코드 (imp_code) 발급
4. REST API Key/Secret 발급
```

**2. HTML/JavaScript 코드**:
```html
<!-- 포트원 SDK 로드 -->
<script src="https://cdn.iamport.kr/v1/iamport.js"></script>

<script>
// 포트원 초기화
var IMP = window.IMP;
IMP.init('imp12345678'); // 상점 식별코드

// 결제 요청
IMP.request_pay({
    pg: 'html5_inicis',           // PG사 (이니시스)
    pay_method: 'card',           // 결제 수단
    merchant_uid: 'ORDER_' + new Date().getTime(), // 주문 번호
    name: '서울미녀 예약',
    amount: 50000,                // 금액
    buyer_email: 'user@example.com',
    buyer_name: '홍길동',
    buyer_tel: '010-1234-5678'
}, function(rsp) {
    if (rsp.success) {
        // 결제 성공
        alert('결제 성공: ' + rsp.imp_uid);
        // 서버에 결제 검증 요청
        verifyPayment(rsp.imp_uid);
    } else {
        // 결제 실패
        alert('결제 실패: ' + rsp.error_msg);
    }
});
</script>
```

**3. 서버 검증 (PHP)**:
```php
<?php
// 포트원 REST API로 결제 검증
$imp_uid = $_POST['imp_uid'];
$merchant_uid = $_POST['merchant_uid'];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://api.iamport.kr/payments/{$imp_uid}");
curl_setopt($ch, CURLOPT_HTTPHEADER, array(
    'Authorization: YOUR_REST_API_KEY'
));
$response = curl_exec($ch);
$payment_data = json_decode($response, true);

// 결제 금액 검증
if ($payment_data['response']['amount'] == $expected_amount) {
    // 결제 완료 처리
    update_order_status($merchant_uid, 'paid');
}
?>
```

**목표**: Frezka 구독 시스템에 한국 PG (INIpay, 포트원) 추가

**방법 1: Laravel Payment Controller 확장**

```php
// Frezka: Modules/Subscriptions/Http/Controllers/SubscriptionController.php

public function subscribeToPlan(Request $request)
{
    $plan = Plan::find($request->plan_id);
    $payment_method = $request->payment_method; // 'inicis', 'portone', 'stripe'

    if ($payment_method == 'inicis') {
        // CareBaby INIpay 결제 로직 호출
        return $this->processInicisPayment($plan);
    } elseif ($payment_method == 'portone') {
        // 포트원 결제 로직
        return $this->processPortOnePayment($plan);
    } else {
        // 기존 Stripe 로직
        return $this->processStripePayment($plan);
    }
}

private function processInicisPayment($plan)
{
    // CareBaby의 INIpay 함수 호출
    require_once base_path('../carebaby/pg/inicis_auth.php');

    $result = inicis_payment_request([
        'amount' => $plan->amount,
        'product_name' => $plan->name,
        'buyer_name' => auth()->user()->name,
        'buyer_email' => auth()->user()->email
    ]);

    if ($result['success']) {
        // 구독 생성
        Subscription::create([
            'user_id' => auth()->id(),
            'plan_id' => $plan->id,
            'payment_id' => $result['transaction_id'],
            'status' => 'active'
        ]);

        return response()->json(['success' => true]);
    }
}
```

```php
// app/Http/Controllers/SocialLoginController.php

use Laravel\Socialite\Facades\Socialite;

public function redirectToKakao()
{
    return Socialite::driver('kakao')->redirect();
}

public function handleKakaoCallback()
{
    $kakao_user = Socialite::driver('kakao')->user();

    // 사용자 조회 또는 생성
    $user = User::firstOrCreate(
        ['email' => $kakao_user->getEmail()],
        [
            'name' => $kakao_user->getName(),
            'kakao_id' => $kakao_user->getId(),
            'profile_image' => $kakao_user->getAvatar()
        ]
    );

    // 로그인 처리
    auth()->login($user);

    return redirect('/subscription/plans');
}
```
