## 🔧 기술 구현

### JavaScript Alert 사용
```html
<a href="#" onclick="alert('개발중입니다'); return false;">링크 텍스트</a>
```

### 작동 방식
1. 링크 클릭 시 JavaScript 실행
2. 브라우저 기본 알림창 표시: "개발중입니다"
3. `return false;`로 페이지 이동 방지
4. `href="#"`로 페이지 최상단 스크롤 방지

## 💡 개선 제안 (선택사항)

### 1. 모던한 토스트 메시지
```html
<div id="toast" class="fixed bottom-4 right-4 bg-orange-500 text-white px-6 py-3 rounded-lg shadow-lg hidden">
    🚧 개발중입니다
</div>

<script>
function showToast() {
    const toast = document.getElementById('toast');
    toast.classList.remove('hidden');
    setTimeout(() => toast.classList.add('hidden'), 2000);
    return false;
}
</script>

<a href="#" onclick="return showToast();">링크</a>
```

### 2. 모달 팝업
```html
<!-- 더 세련된 디자인의 모달 -->
<div id="devModal" class="fixed inset-0 bg-black bg-opacity-50 hidden flex items-center justify-center">
    <div class="bg-white rounded-xl p-8 max-w-sm">
        <h3 class="text-xl font-bold mb-2">🚧 준비 중입니다</h3>
        <p class="text-gray-600 mb-4">빠른 시일 내에 서비스 예정입니다</p>
        <button onclick="closeModal()" class="bg-orange-500 text-white px-6 py-2 rounded-lg">
            확인
        </button>
    </div>
</div>
```
