# 광고 관리 시스템 사용 가이드

## 📋 개요

CareBaby 프로젝트의 광고 관리 시스템은 광고주 등록, 광고 등록/승인, 광고 표시, 통계 관리 기능을 포함한 완전한 광고 플랫폼입니다.

**개발 완료일**: 2025-12-09
**기술 스택**: PHP 8.2.3, NFOR Framework v7.0.7, MySQL/MariaDB, jQuery
**총 파일**: 15개 | **총 코드 라인**: 약 5,700 라인

## 🗄️ 데이터베이스 구조

### 1. nf_advertiser (광고주 정보)
광고주 계정 정보 관리

**주요 컬럼**:
- `advertiser_no` - 광고주 번호 (PK)
- `member_no` - 회원 번호 (FK)
- `advertiser_company` - 회사명/상호
- `advertiser_business_no` - 사업자등록번호
- `advertiser_status` - 상태 (pending/approved/rejected/suspended)
- `advertiser_approved_at` - 승인 일시

### 2. nf_advertisement (광고 정보)
광고 캠페인 정보 관리

**주요 컬럼**:
- `ad_no` - 광고 번호 (PK)
- `advertiser_no` - 광고주 번호 (FK)
- `ad_title` - 광고 제목
- `ad_type` - 광고 유형 (banner/inline/sidebar/popup)
- `ad_position` - 광고 위치 (hospital_list/hospital_view/main/all)
- `ad_image` - 광고 이미지 URL
- `ad_link_url` - 클릭 시 이동 URL
- `ad_start_date` - 광고 시작일
- `ad_end_date` - 광고 종료일
- `ad_status` - 광고 상태 (pending/approved/rejected/active/paused/expired)
- `ad_priority` - 우선순위 (0-100, 높을수록 먼저 노출)
- `ad_view_count` - 총 조회수
- `ad_click_count` - 총 클릭수
- `ad_payment_status` - 결제 상태 (pending/paid/expired)
- `ad_total_price` - 총 광고 비용

### 3. nf_ad_statistics (광고 일별 통계)
일별 광고 성과 통계

**주요 컬럼**:
- `stat_no` - 통계 번호 (PK)
- `ad_no` - 광고 번호 (FK)
- `stat_date` - 통계 날짜
- `stat_view_count` - 일별 조회수
- `stat_click_count` - 일별 클릭수
- `stat_ctr` - CTR (클릭률 %)

### 4. nf_ad_pricing (광고 요금 정보)
광고 요금 체계 관리

**주요 컬럼**:
- `pricing_type` - 요금 유형 (daily/priority/position)
- `daily_price` - 1일 기본 요금 (10,000원)
- `priority_level` - 우선순위 레벨 (10/20/30/50)
- `priority_price` - 우선순위 추가 요금
- `position_type` - 위치 유형 (hospital_view/main/all)
- `position_price` - 위치 추가 요금 (1일 기준)

### 5. nf_ad_payment (광고 결제 정보)
INIpay 결제 내역 관리

**주요 컬럼**:
- `payment_no` - 결제 번호 (PK)
- `ad_no` - 광고 번호 (FK)
- `payment_price` - 결제 금액
- `payment_status` - 결제 상태 (pending/paid/cancelled/refunded)
- `payment_method` - 결제 수단 (card/vbank/trans)
- `tid` - INIpay 거래 ID
- `resultCode` - 결제 결과 코드
- `payment_paid_at` - 결제 완료 일시

### 광고 표시 함수 (4개)

#### 12. ad_get_active_list($position, $limit)
특정 위치의 활성 광고 목록 조회

**파라미터**:
- `$position`: 'hospital_list', 'hospital_view', 'main', 'all'
- `$limit`: 조회 개수 (기본값: 10)

**반환값**: 광고 배열

**사용 예시**:
```php
$ads = ad_get_active_list('hospital_list', 10);
```

#### 13. ad_get_random($position)
랜덤 광고 1개 조회 (우선순위 고려)

**사용 예시**:
```php
$ad = ad_get_random('hospital_list');
if ($ad) {
    echo ad_render($ad, 'inline');
}
```

#### 14. ad_render($ad_data, $template)
광고 HTML 렌더링

**파라미터**:
- `$ad_data`: 광고 정보 배열
- `$template`: 'inline', 'banner', 'sidebar'

**반환값**: 광고 HTML 문자열

#### 15. ad_insert_in_list($items, $position, $interval)
리스트 중간에 광고 삽입

**파라미터**:
- `$items`: 원본 항목 배열 (병원 목록 등)
- `$position`: 광고 위치
- `$interval`: 광고 삽입 간격 (기본값: 5개마다)

**반환값**: 광고가 삽입된 배열
```php
[
    ['type' => 'item', 'data' => 병원 정보],
    ['type' => 'item', 'data' => 병원 정보],
    ['type' => 'ad', 'data' => 광고 정보],
    ...
]
```

**사용 예시**:
```php
// hospital_list.php에서 사용
$items_with_ads = ad_insert_in_list($hospital_list, 'hospital_list', 5);

foreach ($items_with_ads as $item) {
    if ($item['type'] === 'item') {
        // 병원 카드 출력
        echo render_hospital_card($item['data']);
    } else {
        // 광고 출력
        echo ad_render($item['data'], 'inline');
    }
}
```


### 광고 결제 함수 (10개)

#### 21. ad_calculate_price($ad)
광고 요금 계산

**계산 공식**:
```
총 광고 비용 = 기본 요금 + 우선순위 요금 + 위치 요금

기본 요금 = 10,000원 × 일수
우선순위 요금 = 레벨별 고정 요금 (10→50,000원, 20→100,000원, 30→150,000원, 50→300,000원)
위치 요금 = 위치별 1일 요금 × 일수 (hospital_view→5,000원/일, main→30,000원/일, all→50,000원/일)
```

**사용 예시**:
```php
$ad = ad_get_info($ad_no);
$total_price = ad_calculate_price($ad);
echo "총 광고 비용: " . number_format($total_price) . "원";
```

```
    ↓

    ↓
[관리자 승인]
    ↓
advertiser_approve 함수 호출
    ↓

    ↓
광고 등록 가능
```

```dart
import 'dart:convert';
import 'package:http/http.dart' as http;

Future<List<Ad>> getAdList() async {
  final response = await http.get(
    Uri.parse('https://carebaby.com/api/ad_list.php?position=hospital_list&limit=10')
  );

  if (response.statusCode == 200) {
    final data = json.decode(response.body);
    if (data['success']) {
      final ads = data['data']['ads'] as List;
      return ads.map((ad) => Ad.fromJson(ad)).toList();

  }

  throw Exception('Failed to load ads');
}
```

```php
echo htmlspecialchars($ad['ad_title'], ENT_QUOTES, 'UTF-8');
```

## 📊 광고 요금 체계

### 기본 요금
- **1일 기본 요금**: 10,000원
- 예: 30일 광고 = 10,000원 × 30일 = 300,000원

### 우선순위 추가 요금 (고정)
- **우선순위 10**: +50,000원
- **우선순위 20**: +100,000원
- **우선순위 30**: +150,000원
- **우선순위 50**: +300,000원

### 위치 추가 요금 (1일 기준)
- **병원 리스트 (hospital_list)**: 추가 요금 없음 (기본 위치)
- **병원 상세 (hospital_view)**: +5,000원/일
- **메인 페이지 (main)**: +30,000원/일
- **전체 페이지 (all)**: +50,000원/일

### 예시 계산

## 🐛 문제 해결

### 광고가 표시되지 않을 때
1. DB에 활성 광고가 있는지 확인
```sql
SELECT * FROM nf_advertisement
WHERE ad_status = 'active'
AND ad_deleted_at IS NULL
AND ad_start_date <= NOW()
AND ad_end_date > NOW();
```

2. 광고 상태 확인
- `ad_status`가 'active'인지 확인
- `ad_start_date` <= 현재 < `ad_end_date` 확인

3. 날짜 범위 확인

---

### 광고 추적이 안될 때
1. JavaScript 콘솔 에러 확인
2. AJAX 엔드포인트 경로 확인
```javascript
console.log('ad_view_track.php 경로:', '/ad_view_track.php');
```
3. DB 권한 확인
```sql
SHOW GRANTS FOR 'carebaby_user'@'localhost';
```

---

### 이미지가 안보일 때
1. 이미지 파일 경로 확인
2. 파일 권한 확인 (755)
```bash
chmod 755 /path/to/carebaby/data/ad
```
3. 업로드 디렉토리 존재 여부 확인
```bash
ls -la /path/to/carebaby/data/ad/2025/12
```

---

### 결제가 안될 때
1. INIpay 설정 확인
- `$nfor[pg_id]`: 가맹점 ID
- `$nfor[pg_signkey]`: 서명 키

2. 결제 환경 확인
- 테스트: `INIpayTest`
- 상용: 실제 가맹점 ID

3. 결제 로그 확인
```sql
SELECT * FROM nf_ad_payment
WHERE ad_no = 1
ORDER BY payment_created_at DESC;
```
