WHERE JSON_EXTRACT(categories, CONCAT('$[', idx, ']')) IS NOT NULL
GROUP BY category
ORDER BY hospital_count DESC;

## 🔗 KiviCare 연동 가능성

### gangnamunni_hospitals → KiviCare clinic 매핑

| Gangnamunni | KiviCare | 비고 |
|-------------|----------|------|
| id | - | 새로운 ID 필요 |
| name | clinic.name | 직접 매핑 |
| address | clinic.address | 직접 매핑 |
| phone | clinic.contact_number | 직접 매핑 |
| latitude | clinic.latitude | 직접 매핑 |
| longitude | clinic.longitude | 직접 매핑 |
| rating | - | 신규 필드 추가 |
| review_count | - | 신규 필드 추가 |
| categories | clinics_categories | 관계 테이블 생성 |
| treatment_tags | clinics_services | 관계 테이블 생성 |
| business_hours | clinichours | 관계 테이블 생성 |

### 통합 마이그레이션 쿼리 (참고용)

```sql
-- Gangnamunni 데이터를 KiviCare clinic 테이블로 통합
INSERT INTO clinic (name, email, contact_number, address, latitude, longitude, status, created_at, updated_at)
SELECT
  name,
  CONCAT('contact_', id, '@gangnamunni.com') as email,
  phone,
  address,
  latitude,
  longitude,
  1 as status,
  NOW() as created_at,
  NOW() as updated_at
FROM gangnamunni_hospitals
WHERE address IS NOT NULL AND phone IS NOT NULL;
```
