## ⚙️ 설정 파일 위치

**Apache Virtual Host 설정:**
```
C:\xampp\apache\conf\extra\httpd-vhosts.conf
```

**설정 예시 (Dashboard):**
```apache
<VirtualHost *:80>
    ServerName vps20-2-dashboard.seoulbeauty.local
    DocumentRoot "H:/carebaby_project/server_backup_dev/dashboard"

    <Directory "H:/carebaby_project/server_backup_dev/dashboard">
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
        DirectoryIndex index.html index.php
    </Directory>

    ErrorLog "logs/dashboard-error.log"
    CustomLog "logs/dashboard-access.log" common
</VirtualHost>
```

## 🔧 문제 해결

### 403 Forbidden 에러
**원인**: 디렉토리 권한 문제
**해결**:
```apache
<Directory "경로">
    Require all granted
    AllowOverride All
</Directory>
```

### 도메인 접근 불가
**원인**: hosts 파일 미설정 또는 Apache 미재시작
**해결**:
1. hosts 파일 확인
2. Apache 재시작
3. `ping vps20-2-dashboard.seoulbeauty.local` 테스트

### Laravel 500 에러
**원인**: 권한 문제
**해결**:
```bash
icacls "경로\storage" /grant Everyone:(OI)(CI)F /T
icacls "경로\bootstrap\cache" /grant Everyone:(OI)(CI)F /T
php artisan config:clear
php artisan cache:clear
```
