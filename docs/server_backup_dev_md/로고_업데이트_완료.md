```html

    <span class="text-xl font-bold text-gray-900">서울미녀</span>
</a>

<!-- Footer -->
<div class="flex items-center gap-3 mb-4">
    <img src="seoulbeuty_logo.png" alt="서울미녀" class="h-10 w-auto">
    <span class="text-xl font-bold text-white">서울미녀</span>
</div>
```

### Tailwind CSS
- `h-10`: 높이 40px (2.5rem)
- `w-auto`: 가로 비율 유지
- `gap-3`: 로고와 텍스트 간격 12px
