## 1. 프로젝트 개요

### 1.1 전체 프로젝트 구성

CareBaby 프로젝트는 **병원 정보 플랫폼**으로 다음과 같은 구성 요소를 포함합니다:

- **백엔드 서버**: Laravel 기반 웹 애플리케이션 (`kivicare-laravel-web-v1.9.0`)
- **모바일 애플리케이션**: Flutter 기반 3개 앱 (`kivicare-app`)
- **관리 대시보드**: HTML 기반 관리자 페이지 (`dashboard`)
- **레거시 시스템**: PHP 기반 CareBaby 시스템 (`carebaby`)

### 1.2 모바일 관련 소스 위치

프로젝트 내 모바일 관련 소스는 다음 위치에 있습니다:

```

│   ├── frezka_customer_app _v4.0.3/       # 고객용 뷰티 살롱 앱
```

**경로**: `h:\carebaby_project\server_backup_dev\carebaby\`

#### 주요 모바일 관련 파일 (44개)

```
carebaby/
├── mobile.php                             # 모바일 메인 페이지
├── css/style_mobile.css                  # 모바일 CSS
└── PG 연동 파일 (INICIS 이니시스):
    ├── pg_inipay_mobile.php              # 일반 결제
    ├── pg_inipay_mobile_ad.php           # 광고 결제
    ├── pg_inipay_mobile_membership.php   # 멤버십 결제
    ├── pg_inipay_mobile_noti.php         # 결제 알림
    ├── pg_inipay_mobile_update.php       # 결제 업데이트
    ├── manager_pg_inipay_mobile.php      # 관리자 결제
    └── ... (총 44개 모바일 PG 관련 파일)
```

**기능**:
- ✅ INICIS(이니시스) 모바일 PG 연동

**특징**:
- **재사용 가능**: Flutter 앱에서 WebView로 호출 가능

## 3. 각 모바일 앱 상세 분석

### 3.1 Frezka Customer App (추천 ⭐)

#### 개발 언어
- **주 언어**: Dart (Flutter 3.0+)
- **지원 플랫폼**: Android, iOS

#### 상태 관리
- **MobX**: Reactive State Management
  - `AppStore`: 앱 전역 상태
  - `UserStore`: 사용자 정보
  - `BookingRequestStore`: 예약 요청
  - `ProductStore`: 제품 관리
  - `RolesAndPermissionStore`: 권한 관리

#### 주요 기능

| 기능 카테고리 | 세부 기능 | 화면 경로 |
|------------|---------|---------|
| **인증** | 로그인, 회원가입, 소셜 로그인 (Google, Apple) | `screens/auth/` |
| **예약** | 서비스 예약, 타임슬롯 선택, 전문가 선택 | `screens/booking/` |
| **뷰티 서비스** | 살롱 검색, 서비스 카테고리, 인기 서비스 | `screens/services/`, `screens/branch/` |
| **전문가** | 스태프 목록, 전문가 상세, 리뷰 | `screens/experts/` |
| **쇼핑** | 제품 쇼핑, 장바구니, 위시리스트 | `screens/product/`, `screens/cart/` |
| **패키지** | 패키지 구매, 쿠폰 시스템 | `screens/package/`, `screens/coupons/` |
| **결제** | 10개 글로벌 PG 연동 | `paymentGateways/` |
| **프로필** | 마이페이지, 예약 내역, 주문 내역 | `screens/profile/` |
| **월렛** | 포인트 충전, 출금, 거래 내역 | `screens/wallet/`, `screens/withdraw/` |
| **기타** | 알림, 리뷰, 지도 검색 | `screens/notifications/`, `screens/review/` |

#### 결제 게이트웨이 (10개)
1. **Razorpay** (인도)
2. **Stripe** (글로벌)
3. **PayPal** (글로벌)

5. **CinetPay** (아프리카)

8. **Paystack** (나이지리아)
9. **가상계좌** (Virtual Bank)
10. **COD** (현금 결제)

#### 다국어 지원 (7개)
- ✅ English (en)
- ✅ Arabic (ar)
- ✅ German (de)
- ✅ Spanish (es)
- ✅ French (fr)
- ✅ Hindi (hi)
- ✅ **Korean (ko)** - 설정 완료 (`DEFAULT_LANGUAGE = 'ko'`)

```bash
        keyAlias keystoreProperties['keyAlias']

        storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
        storePassword keystoreProperties['storePassword']
    }
}

```
