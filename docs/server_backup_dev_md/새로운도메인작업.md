## 📄 파일 세부 내용

### 1. vps20-2-carebaby.seoulbeauty.app.conf

```apache
<VirtualHost *:80>
    ServerName vps20-2-carebaby.seoulbeauty.app
    DocumentRoot /var/www/html/hospital/carebaby

    # Cloudflare HTTPS detection
    SetEnvIf X-Forwarded-Proto "https" HTTPS=on

    <Directory /var/www/html/hospital/carebaby>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    # Use PHP 7.0
    <FilesMatch \.php$>
        SetHandler "proxy:unix:/opt/php70/var/run/php-fpm.sock|fcgi://localhost"
    </FilesMatch>

    ErrorLog /var/log/httpd/carebaby-seoulbeauty-error.log
    CustomLog /var/log/httpd/carebaby-seoulbeauty-access.log combined
</VirtualHost>
```

**특징**:
- PHP 7.0 전용 설정 (레거시 프로젝트)
- Cloudflare HTTPS 프록시 지원
- 인덱스 리스팅 비활성화

### 5. seoulbeauty.app.conf (메인 도메인)

```apache
<VirtualHost *:80>
    ServerName seoulbeauty.app
    DocumentRoot /var/www/html/hospital

    # Cloudflare HTTPS detection
    SetEnvIf X-Forwarded-Proto "https" HTTPS=on

    <Directory /var/www/html/hospital>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted

        # 기본 파일 설정
        DirectoryIndex index.php index.html

        # Rewrite 규칙
        <IfModule mod_rewrite.c>
            RewriteEngine On
            RewriteBase /

            # 실제 파일/디렉토리가 아니면 index.php로 라우팅
            RewriteCond %{REQUEST_FILENAME} !-f
            RewriteCond %{REQUEST_FILENAME} !-d
            RewriteRule ^(.*)$ index.php [L,QSA]
        </IfModule>
    </Directory>

    ErrorLog /var/log/httpd/seoulbeauty-error.log
    CustomLog /var/log/httpd/seoulbeauty-access.log combined
</VirtualHost>
```

**특징**:
- **index.php 라우팅 설정**: 모든 요청을 index.php로 전달
- **Rewrite 규칙**: 파일이 존재하지 않으면 index.php 실행
- Cloudflare HTTPS 프록시 지원

## 💡 중요 참고사항

### 1. /var/www/html/hospital/index.php 파일 필요

메인 도메인(`seoulbeauty.app`, `www.seoulbeauty.app`)이 정상 작동하려면 다음 파일이 존재해야 합니다:

```
/var/www/html/hospital/index.php
```

이 파일이 없으면 **404 Not Found** 에러가 발생합니다.

### 2. mod_rewrite 모듈 필요

메인 도메인의 URL 라우팅을 위해 Apache `mod_rewrite` 모듈이 활성화되어 있어야 합니다:

```bash
# 모듈 활성화 확인
httpd -M | grep rewrite

# 예상 출력:
# rewrite_module (shared)
```

### 3. 기존 apppia.com 도메인과 공존 가능

새로운 `seoulbeauty.app` 설정 파일은 기존 `apppia.com` 파일과 함께 작동합니다. 두 도메인 모두 동시에 사용 가능합니다.

### 4. 도메인 전환 시 주의사항

- **데이터베이스 URL 설정**: Laravel `.env` 파일에서 `APP_URL` 변경 필요
- **세션/쿠키**: 도메인 변경 시 기존 세션 무효화됨
- **CORS 설정**: API 도메인이 변경되면 CORS 정책 업데이트 필요
