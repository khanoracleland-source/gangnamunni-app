## 1. 분석 개요

### 1.1 분석 대상 문서

프로젝트 내 다음 markdown 파일들을 분석하여 최적의 앱 개발 방법을 도출했습니다:

- ✅ `kivicare-app/앱분석및개발.md` - 상세한 앱 분석 및 개발 계획서
- ✅ `kivicare-app/앱전체소스분석.md` - 전체 소스 코드 구조 분석
- ✅ `모바일-개발방법.md` - 모바일 소스 분석 및 사용 가이드
- ✅ `kivicare-app/앱_패키지_정보.md` - Firebase 및 패키지 정보

### 1.2 프로젝트 구성

CareBaby 프로젝트는 다음과 같은 모바일 앱을 포함하고 있습니다:

```
h:\carebaby_project\server_backup_dev\
├── kivicare-app/
│   ├── frezka_customer_app _v4.0.3/              # 고객용 뷰티 살롱 앱
│   └── kivicare-complete-clinic-flutter-apps/

│       └── clinic-admin-vendor-app/               # 병원 관리자 앱
└── carebaby/
    └── pg_inipay_mobile*.php                      # PHP 레거시 모바일 PG (44개 파일)
```

## 2. 사용 가능한 앱 분석

### 2.1 Frezka Customer App v4.0.3 ⭐⭐⭐⭐⭐

#### 기본 정보
- **타입**: 고객용 뷰티/살롱 서비스 예약 앱
- **언어**: Dart (Flutter 3.0+)
- **버전**: 4.0.3+32
- **패키지명**: `com.frezka.customer`
- **상태 관리**: MobX
- **파일 수**: 343개 Dart 파일

#### 주요 기능
| 카테고리 | 기능 |
|---------|------|
| 🔐 **인증** | 이메일/비밀번호, Google, Apple 소셜 로그인, OTP 인증 |
| 📅 **예약** | 지점 선택, 서비스 선택, 전문가 선택, 타임슬롯, 예약 관리 |
| 💇 **뷰티 서비스** | 살롱 검색, 카테고리, 인기 서비스, 리뷰 시스템 |
| 🛍️ **E-commerce** | 제품 쇼핑, 장바구니, 위시리스트, 주문 관리 |
| 🎁 **패키지/쿠폰** | 패키지 구매, 유효기간 관리, 쿠폰 시스템 |
| 💳 **결제** | 10개 글로벌 PG (Razorpay, Stripe, PayPal 등) |
| 💰 **월렛** | 포인트 충전, 출금, 거래 내역, 은행 계좌 관리 |
| 👤 **프로필** | 마이페이지, 예약 내역, 주문 내역 |
| 🗺️ **지도** | Google Maps 기반 주변 검색 |
| 🌍 **다국어** | 7개 언어 (영어, 아랍어, 독일어, 스페인어, 프랑스어, 힌디어, **한국어** ✅) |

#### 기술 스택
```yaml
상태 관리: MobX (Reactive State Management)
네트워크: HTTP (REST API)
Firebase: Auth, FCM, Crashlytics, Storage, Firestore
지도: Google Maps, Geolocator, Geocoding
이미지: image_picker, cached_network_image
결제 PG: 10개 (Razorpay, Stripe, PayPal, Flutterwave, PhonePe, Paystack, CinetPay, Midtrans, Sadad, Airtel Money)
```

#### 장점
- ✅ **가장 완성도 높은 앱** - 예약 + E-commerce + 결제 + 월렛 통합
- ✅ **한국어 지원 완료** - `DEFAULT_LANGUAGE = 'ko'` 설정됨
- ✅ **다양한 결제 옵션** - 10개 글로벌 PG 연동
- ✅ **체계적인 아키텍처** - MobX Store Pattern
- ✅ **Firebase 완전 통합** - 인증, FCM, Crashlytics
- ✅ **E-commerce 기능** - 제품 판매 가능

#### 단점
- ⚠️ 병원 특화 기능 부족 (진료 기록, 처방전 등)
- ⚠️ 관리자 기능 없음 (고객용만 제공)

#### 사용 추천 상황
```
✅ 뷰티/살롱 서비스 제공 (미용실, 네일샵, 스파)
✅ 제품 판매 필요 (화장품, 미용 제품)
✅ 패키지/쿠폰 시스템 필요
✅ 다양한 결제 수단 필요
✅ 소셜 로그인 필요
✅ E-commerce + 예약 통합 플랫폼
```

## 4. 추천 앱 및 사용 방법

### 4.1 최종 추천: Frezka Customer App ⭐⭐⭐⭐⭐

#### 선택 이유

**1. 가장 완성도 높은 앱**
- 예약 + E-commerce + 결제 + 월렛 통합
- 343개 Dart 파일, 체계적인 아키텍처
- MobX Store Pattern으로 유지보수 용이

**2. 한국어 지원 완료**
- `DEFAULT_LANGUAGE = 'ko'` 설정됨
- 1,250+개 번역 키 한국어 번역 완료
- 즉시 사용 가능

**3. 다양한 결제 옵션**
- 10개 글로벌 PG 연동 (Razorpay, Stripe, PayPal 등)
- CareBaby INICIS PG 추가 가능 (WebView)
- 월렛 시스템 완비

**4. 확장 가능성**
- E-commerce 기능으로 제품 판매 가능
- 패키지/쿠폰 시스템으로 마케팅 강화
- 모듈화된 구조로 기능 추가 쉬움

**5. Firebase 완전 통합**
- Authentication (Google, Apple 소셜 로그인)
- FCM (푸시 알림)
- Crashlytics (에러 추적)
- Firestore (실시간 데이터베이스)
- Storage (이미지 저장)

### 4.2 사용 방법

#### Step 1: 환경 설정

```bash
# 1. 프로젝트 이동
cd "kivicare-app/frezka_customer_app _v4.0.3"

# 2. Flutter 패키지 설치
```

```dart
// lib/paymentGateways/services/inicis_service.dart (신규 생성)

import 'package:webview_flutter/webview_flutter.dart';
import 'package:url_launcher/url_launcher.dart';

class InicisPaymentService {
  // INICIS 모바일 PG 호출
  Future<PaymentResponse> processPayment({
    required String orderNumber,
    required double amount,
    required String productName,
    required String buyerName,
    required String buyerEmail,
    required String buyerTel,
  }) async {
    // 1. Carebaby 서버 pg_inipay_mobile.php URL 생성
    final url = Uri.parse('${DOMAIN_URL}/carebaby/pg_inipay_mobile.php').replace(
      queryParameters: {
        'order_number': orderNumber,
        'amount': amount.toString(),
        'product_name': productName,
        'buyer_name': buyerName,
        'buyer_email': buyerEmail,
        'buyer_tel': buyerTel,
        'app_scheme': 'carebaby://',  // 앱 복귀용 스키마
      },
    );

    // 2. WebView로 결제창 오픈
    final result = await Navigator.push(
      context,
      MaterialPageRoute(
        builder: (context) => InicisPaymentWebView(url: url.toString()),
      ),
    );

    return result ?? PaymentResponse(status: 'failed', message: '결제 취소');
  }
}

// WebView 화면
class InicisPaymentWebView extends StatefulWidget {
  final String url;
  const InicisPaymentWebView({required this.url});

  @override
  State<InicisPaymentWebView> createState() => _InicisPaymentWebViewState();
}

class _InicisPaymentWebViewState extends State<InicisPaymentWebView> {
  late final WebViewController controller;

  @override
  void initState() {
    super.initState();
    controller = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..setNavigationDelegate(
        NavigationDelegate(
          onNavigationRequest: (request) {
            // 앱 스키마로 복귀 감지
            if (request.url.startsWith('carebaby://')) {
              _handlePaymentResult(request.url);
              return NavigationDecision.prevent;
            }
            return NavigationDecision.navigate;
          },
        ),
      )
      ..loadRequest(Uri.parse(widget.url));
  }

  void _handlePaymentResult(String url) {
    // URL에서 결제 결과 파싱
    final uri = Uri.parse(url);
    final status = uri.queryParameters['status'];
    final tid = uri.queryParameters['tid'];

    Navigator.pop(
      context,
      PaymentResponse(
        status: status == 'success' ? 'success' : 'failed',
        transactionId: tid,
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('결제')),
      body: WebViewWidget(controller: controller),
    );
  }
}
```

## 📞 기술 지원

### 문제 해결 가이드

**Flutter 빌드 실패 시**:
```bash
# 1. 캐시 삭제
flutter clean

# 2. 패키지 재설치
flutter pub get

# 3. MobX 코드 재생성
dart run build_runner build --delete-conflicting-outputs

# 4. 재빌드
flutter run
```

**API 연결 실패 시**:
```dart
// configs.dart 확인
const DOMAIN_URL = "https://yourdomain.com";  // ⚠️ 실제 서버 주소 확인

// 네트워크 권한 확인 (AndroidManifest.xml)
<uses-permission android:name="android.permission.INTERNET" />
```

**Firebase 연동 실패 시**:
```
1. google-services.json 파일 확인 (android/app/)
2. GoogleService-Info.plist 파일 확인 (ios/Runner/)
3. 패키지명 일치 확인: com.frezka.customer
4. Firebase Console에서 앱 등록 확인
```
