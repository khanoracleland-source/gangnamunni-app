#### 2-2. InicisPaymentService 구현

**새 파일 생성**: `lib/paymentGateways/services/inicis_service.dart`

```dart
import 'package:flutter/material.dart';
import 'package:webview_flutter/webview_flutter.dart';
import '../../configs.dart';

class InicisPaymentService {
  /// INICIS 모바일 PG 결제 처리
  Future<Map<String, dynamic>> processPayment({
    required BuildContext context,
    required String orderNumber,
    required double amount,
    required String productName,
    required String buyerName,
    required String buyerEmail,
    required String buyerTel,
  }) async {
    // INICIS 결제 URL 생성
    final url = Uri.parse('${DOMAIN_URL}/carebaby/pg_inipay_mobile.php').replace(
      queryParameters: {
        'order_number': orderNumber,
        'amount': amount.toStringAsFixed(0),
        'product_name': productName,
        'buyer_name': buyerName,
        'buyer_email': buyerEmail,
        'buyer_tel': buyerTel,
        'app_scheme': 'carebaby://',  // 앱 복귀용 스키마
      },
    );

    // WebView로 결제창 오픈
    final result = await Navigator.push(
      context,
      MaterialPageRoute(
        builder: (context) => InicisPaymentWebView(url: url.toString()),
      ),
    );

    return result ?? {'status': 'failed', 'message': '결제 취소'};
  }
}

/// INICIS 결제 WebView 화면
class InicisPaymentWebView extends StatefulWidget {
  final String url;

  const InicisPaymentWebView({Key? key, required this.url}) : super(key: key);

  @override
  State<InicisPaymentWebView> createState() => _InicisPaymentWebViewState();
}

class _InicisPaymentWebViewState extends State<InicisPaymentWebView> {
  late final WebViewController _controller;
  bool _isLoading = true;

  @override
  void initState() {
    super.initState();
    _initWebView();
  }

  void _initWebView() {
    _controller = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..setNavigationDelegate(
        NavigationDelegate(
          onPageStarted: (url) {
            setState(() => _isLoading = true);
          },
          onPageFinished: (url) {
            setState(() => _isLoading = false);
          },
          onNavigationRequest: (request) {
            // 앱 스키마로 복귀 감지
            if (request.url.startsWith('carebaby://')) {
              _handlePaymentResult(request.url);
              return NavigationDecision.prevent;
            }
            return NavigationDecision.navigate;
          },
        ),
      )
      ..loadRequest(Uri.parse(widget.url));
  }

  void _handlePaymentResult(String url) {
    final uri = Uri.parse(url);
    final status = uri.queryParameters['status'] ?? 'failed';
    final tid = uri.queryParameters['tid'] ?? '';
    final message = uri.queryParameters['message'] ?? '';

    Navigator.pop(context, {
      'status': status,
      'transaction_id': tid,
      'message': message,
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('결제'),
        leading: IconButton(
          icon: Icon(Icons.close),
          onPressed: () => Navigator.pop(context),
        ),
      ),
      body: Stack(
        children: [
          WebViewWidget(controller: _controller),
          if (_isLoading)
            Center(child: CircularProgressIndicator()),
        ],
      ),
    );
  }
}
```

##### 3-4-4. 통화 포맷팅

**lib/utils/format_utils.dart** (신규 생성):
```dart
import 'package:intl/intl.dart';

class FormatUtils {
  /// 원화 가격 포맷 (예: 50000 → "50,000원")
  static String formatKRW(double amount) {
    final formatter = NumberFormat('#,###', 'ko_KR');
    return '${formatter.format(amount)}원';
  }

  /// 전화번호 포맷 (예: 01012345678 → "010-1234-5678")
  static String formatPhoneNumber(String phone) {
    if (phone.length == 11) {
      return '${phone.substring(0, 3)}-${phone.substring(3, 7)}-${phone.substring(7)}';
    }
    return phone;
  }

  /// 날짜 포맷
  static String formatDate(DateTime date, {String format = 'yyyy.MM.dd (E) HH:mm'}) {
    return DateFormat(format, 'ko_KR').format(date);
  }
}
```

**사용 예시**:
```dart
Text(FormatUtils.formatKRW(50000))  // "50,000원"
Text(FormatUtils.formatPhoneNumber('01012345678'))  // "010-1234-5678"
```

#### 4-4. Firebase FCM 설정

**Laravel 백엔드에서 FCM 전송**:

**app/Services/FCMService.php** (신규 생성):
```php
<?php

namespace App\Services;

use Kreait\Firebase\Factory;
use Kreait\Firebase\Messaging\CloudMessage;

class FCMService
{
    protected $messaging;

    public function __construct()
    {
        $factory = (new Factory)->withServiceAccount(config('firebase.credentials'));
        $this->messaging = $factory->createMessaging();
    }

    public function sendNotification($deviceToken, $title, $body, $data = [])
    {
        $message = CloudMessage::withTarget('token', $deviceToken)
            ->withNotification([
                'title' => $title,
                'body' => $body,
            ])
            ->withData($data);

        return $this->messaging->send($message);
    }
}
```

**사용 예시**:
```php
// 예약 완료 시 푸시 알림
$fcmService = new FCMService();
$fcmService->sendNotification(
    $user->fcm_token,
    '예약 완료',
    '예약이 성공적으로 완료되었습니다.',
    ['booking_id' => $booking->id]
);
```
