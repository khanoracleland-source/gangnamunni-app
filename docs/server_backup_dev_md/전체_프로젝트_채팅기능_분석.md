## 🎨 Frezka Chat CSS 참고

**발견된 스타일:**
```scss
// 채팅 탭
.iq-chat-tab.nav-tabs {
  .nav-link {
    &.active, &:hover {
      color: var(--primary);
    }
  }
}

// 채팅 콘텐츠
.iq-chating-content {
  background-color: $card-bg;
  border-color: $border-color;
}

// 사용자 리스트
.iq-userlist-data {
  .iq-userlist-name {
    color: $white;
  }
}
```

**활용 방법:**
1. Frezka의 `scss/dark/components/pro/chat/_chat.scss` 파일 복사
2. KiviCare의 스타일 구조에 맞게 수정
3. Vue 3 컴포넌트에 적용
