## ⚠️ 발견된 문제점

### 🔴 심각 (즉시 수정 필요)

#### 1. **KiviCare 데이터베이스 설정 오류**

**파일**: `kivicare-laravel-web-v1.9.0/.env`

```env
# 현재 (잘못됨)
DB_DATABASE=frezka

# 올바른 설정
DB_DATABASE=kivicare_laravel
```

**문제**: KiviCare가 Frezka 데이터베이스를 사용하고 있어 충돌 발생
**영향**: KiviCare 접속 시 테이블 없음 오류
**해결**: `.env` 파일 수정 후 마이그레이션 실행 필요

#### 2. **Apache DocumentRoot 중복 경로 문제**

**파일**: `httpd/conf.d/vps20-2-frezka.seoulbeauty.app.conf`

```apache
# 현재 (중복 경로)
DocumentRoot /var/www/html/hospital/frezka_admin_panel_v4.0.3/frezka_admin_panel_v4.0.3/public

# 올바른 경로
DocumentRoot /var/www/html/hospital/frezka_admin_panel_v4.0.3/public
```

**동일 문제**: `httpd/conf.d/vps20-2-kivicare.seoulbeauty.app.conf`
```apache
# 현재
DocumentRoot /var/www/html/hospital/kivicare-laravel-web-v1.9.0/kivicare-laravel-web-v1.9.0/public

# 올바른 경로
DocumentRoot /var/www/html/hospital/kivicare-laravel-web-v1.9.0/public
```

**문제**: 폴더명이 중복으로 들어가 있음
**영향**: 서버 배포 시 404 에러 발생 가능
**해결**: Apache 설정 수정 및 서버 경로 정리

#### 3. **Frezka APP_URL 설정 불일치**

**파일**: `frezka_admin_panel_v4.0.3/.env`

```env
# 현재
APP_URL=http://vps20-2-frezka-paikpc.seoulbeauty.local

# 문서에 명시된 올바른 URL
APP_URL=http://frezka.seoulbeauty.local
```

**문제**: 로컬 도메인 설정과 .env 설정이 불일치
**영향**: Asset 경로 오류, Mixed Content 경고
**해결**: .env 파일 수정 필요

## ✅ 즉시 수정 작업

### 1. KiviCare 데이터베이스 설정 수정

```bash
# 1. .env 파일 수정
cd kivicare-laravel-web-v1.9.0
# DB_DATABASE=kivicare_laravel로 변경

# 2. 데이터베이스 생성 (필요시)
# MySQL에서: CREATE DATABASE kivicare_laravel;

# 3. 마이그레이션 실행
php artisan migrate:fresh --seed
```

### 2. Apache 설정 경로 수정

```bash
# 서버에서 실행
# 1. 폴더 구조 확인
ls -la /var/www/html/hospital/

# 2. 중복 경로 확인
# 예: frezka_admin_panel_v4.0.3/frezka_admin_panel_v4.0.3 → frezka_admin_panel_v4.0.3

# 3. Apache 설정 파일 수정
# httpd/conf.d/*.conf 파일들의 DocumentRoot 경로 수정

# 4. Apache 재시작
systemctl restart httpd
```

### 3. Frezka .env URL 수정

```bash
cd frezka_admin_panel_v4.0.3

# .env 파일에서 수정
# APP_URL=http://frezka.seoulbeauty.local

# 캐시 클리어
php artisan config:clear
php artisan cache:clear
```
