## 4. 언어 시스템 동작 원리

### 4.1 언어 로딩 흐름

```
┌─────────────────────────────────────────────────────────────┐
│                    사용자 요청                               │
└─────────────────────────┬───────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  SetLocale Middleware                                        │
│  - 세션에서 locale 확인                                       │
│  - App::setLocale('ko') 설정                                 │
└─────────────────────────┬───────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  Blade Template (app.blade.php)                              │
│  - lang/ko/*.php 파일들 로드                                  │
│  - DB 번역 병합 (Languages 테이블)                            │
│  - window.localMessagesUpdate 객체 생성                       │
└─────────────────────────┬───────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  Vue 3 + vue-i18n                                            │
│  - $t('key') 함수로 번역 텍스트 출력                          │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 Blade 템플릿 사용법

```php
// 단순 번역
{{ __('messages.save') }}          // "저장"
{{ __('messages.cancel') }}        // "취소"

// 파라미터 포함
{{ __('messages.Welcome to', ['name' => $appName]) }}
// "관리자 대시보드에 오신 것을 환영합니다"
```

### 4.3 Vue 컴포넌트 사용법

```vue
<template>
  <button>{{ $t('messages.save') }}</button>
  <span>{{ $t('messages.Welcome to', {name: appName}) }}</span>
</template>
```

## 5. 번역 작업 가이드

### 5.1 파일 형식

```php
<?php
// lang/ko/messages.php

return [
    // 기본 버튼
    'yes' => '예',
    'no' => '아니오',
    'save' => '저장',
    'cancel' => '취소',
    'delete' => '삭제',
    'edit' => '수정',
    'add' => '추가',
    'search' => '검색',

    // 파라미터 포함 (변수는 그대로 유지)
    'Welcome to' => ':name 관리자 대시보드에 오신 것을 환영합니다.',
    'total_items' => '총 :count 개의 항목',

    // 긴 문장
    'confirm_delete' => '정말로 이 항목을 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다.',
];
```

### 5.2 번역 우선순위

**1순위 (핵심):**
- `messages.php` - 모든 페이지의 공통 UI
- `auth.php` - 로그인/회원가입
- `validation.php` - 폼 검증 메시지
- `dashboard.php` - 대시보드

**2순위 (기능별):**
- `booking.php` / `appointment.php` - 예약
- `customer.php` / `patient.php` - 고객/환자
- `service.php` - 서비스
- `employee.php` - 직원

**3순위 (설정):**
- `setting_*.php` - 각종 설정 페이지

### 5.3 번역 시 주의사항

1. **변수 유지**: `:name`, `:count` 등 콜론으로 시작하는 변수는 그대로 유지
2. **HTML 태그**: `<br>`, `<strong>` 등 HTML 태그는 그대로 유지
3. **특수문자**: 따옴표('), 쌍따옴표(")는 이스케이프 처리 (`\'`, `\"`)
4. **키 변경 금지**: 배열 키(key)는 절대 변경하지 않음

## 7. 데이터베이스 기반 번역 (선택사항)

두 프로젝트 모두 `languages` 테이블을 통한 DB 기반 번역을 지원합니다.

### 7.1 테이블 구조

```sql
CREATE TABLE languages (
    id          BIGINT UNSIGNED PRIMARY KEY,
    key         VARCHAR(255),      -- 번역 키
    value       VARCHAR(255),      -- 번역 값
    language    VARCHAR(10),       -- 언어 코드 (ko, en 등)
    file        VARCHAR(50),       -- 파일명 (messages, auth 등)
    created_at  TIMESTAMP,
    updated_at  TIMESTAMP
);
```

### 7.2 DB 번역 추가 예시

```sql
INSERT INTO languages (key, value, language, file, created_at, updated_at)
VALUES
('save', '저장하기', 'ko', 'messages', NOW(), NOW()),
('cancel', '취소하기', 'ko', 'messages', NOW(), NOW());
```

**참고**: DB 번역은 파일 번역을 오버라이드합니다. 관리자 UI에서 번역 수정 시 DB에 저장됩니다.

## 8. 추가 정보

### 8.1 RTL/LTR 지원

- 한국어는 LTR (Left-to-Right) 언어입니다.
- 별도의 RTL 설정이 필요하지 않습니다.

### 8.2 날짜/시간 로케일

Carbon 라이브러리가 자동으로 한국어 날짜 형식을 지원합니다.

```php
Carbon::setLocale('ko');
// "2025년 12월 9일 월요일"
```

### 8.3 숫자 형식

한국어 로케일에서 숫자는 기본적으로 콤마(,) 구분자를 사용합니다.
```
1,000,000원
```
