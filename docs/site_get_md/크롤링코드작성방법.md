# 웹사이트 크롤링 스크립트 생성 프롬프트

다음 프롬프트를 Claude CLI에 복사하여 사용하세요. URL을 원하는 사이트로 변경하면 됩니다.

---

## 프롬프트

```
Playwright를 사용해서 웹사이트를 크롤링하고 로컬에 저장하는 Node.js 스크립트를 만들고 실행해줘.

## 대상 사이트
{여기에 크롤링할 URL 입력}

## 핵심 요구사항

### 크롤링 규칙
- 같은 도메인 내 모든 링크를 재귀적으로 방문
- 각 페이지의 JavaScript 렌더링 완료 후 HTML 저장
- 이미지, CSS, JS, 폰트 등 모든 리소스 파일도 다운로드
- 원본 사이트의 디렉토리 구조 그대로 유지
- 한글 파일명/경로 깨지지 않게 UTF-8 처리
- 이미 방문한 URL 중복 방문 방지
- 최대 페이지 수 제한: 1000
- 명령줄 인자로 URL 전달 가능하도록 구현 (node crawler.js <URL>)

### 차단 방지
- 요청 간 2~5초 랜덤 딜레이 적용
- User-Agent를 실제 Chrome 브라우저처럼 설정
- 필요시 요청 헤더에 Referer 포함

### 저장 구조
- ./output/{도메인명}/ 폴더에 저장
- 원본 디렉토리 구조 유지
- 도메인명은 URL에서 자동 추출

### 결과 리포트
크롤링 완료 후 {도메인명}_report.md 파일 생성:
- 크롤링 시작/종료 시간
- 총 방문 페이지 수
- 다운로드한 리소스 수 (이미지, CSS, JS 각각)
- 실패한 URL 목록과 에러 메시지
- 총 다운로드 용량
- 크롤링 소요 시간

### 콘솔 출력
- 실시간 진행 상황: [현재/전체] URL
- 에러 발생 시 표시
- 시작/완료 시 명확히 표시

### 에러 처리
- 개별 페이지 실패해도 전체 크롤링 계속 진행
- 타임아웃 30초, 실패 시 1회 재시도
- 네트워크 에러는 로그에 기록하고 스킵

## 실행
- package.json 생성하고 npm install 실행
- npx playwright install chromium 실행
- 스크립트 실행까지 완료

## 중요
- 중간에 질문하지 말고 끝까지 실행
- 완료 후 {도메인명}_report.md에 모든 결과 기록
- URL을 명령줄 인자로 받을 수 있게 구현
```

## 주요 기능

1. **완전한 사이트 복제**: JavaScript로 렌더링된 최종 HTML 저장
2. **리소스 다운로드**: 이미지, CSS, JS, 폰트 등 모든 리소스
3. **구조 유지**: 원본 사이트의 디렉토리 구조 그대로 보존
4. **차단 방지**: 랜덤 딜레이와 실제 브라우저 User-Agent 사용
5. **에러 복구**: 개별 페이지 실패 시에도 전체 크롤링 계속
6. **상세 리포트**: 크롤링 결과를 마크다운 문서로 자동 생성
7. **유연한 실행**: 명령줄 인자로 다른 URL 크롤링 가능

## 커스터마이징 옵션

스크립트 상단의 CONFIG 객체를 수정하여 설정 변경 가능:

```javascript
const CONFIG = {
  startUrl: 'https://example.com',  // 시작 URL
  domain: 'example.com',             // 도메인
  outputDir: './output/example.com', // 출력 디렉토리
  maxPages: 1000,                    // 최대 페이지 수
  timeout: 30000,                    // 타임아웃 (밀리초)
  minDelay: 2000,                    // 최소 딜레이
  maxDelay: 5000,                    // 최대 딜레이
  retryAttempts: 1                   // 재시도 횟수
};
```

5. **개인정보**: 개인정보가 포함된 페이지는 크롤링하지 마세요

## 문제 해결

### 타임아웃 에러
- CONFIG.timeout 값을 늘리세요 (예: 60000)
- 네트워크 연결 상태를 확인하세요

### 메모리 부족
- CONFIG.maxPages 값을 줄이세요
- headless 모드를 유지하세요

### 한글 깨짐
- 스크립트는 이미 UTF-8 처리가 되어 있으므로 문제없음
- Windows에서는 터미널 인코딩을 UTF-8로 설정: `chcp 65001`
