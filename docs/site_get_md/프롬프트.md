# 웹사이트 크롤러 생성 프롬프트

다른 Claude CLI에 아래 프롬프트를 복사-붙여넣기하고 URL만 수정하세요.

---

## 📋 복사할 프롬프트

```
Playwright 웹 크롤러를 만들어줘.

## 대상 URL
https://example.com

## 요구사항

### 기본 기능
- 같은 도메인 내 모든 링크를 재귀적으로 방문하여 크롤링
- JavaScript 렌더링 완료 후 HTML 저장
- 이미지, CSS, JS, 폰트 등 모든 리소스 파일 다운로드
- 원본 디렉토리 구조 유지
- 한글 경로/파일명 UTF-8 처리
- 중복 URL 방문 방지
- 최대 1000페이지까지 크롤링
- 명령줄 인자로 URL 전달 가능: `node crawler.js <URL>`

### 차단 방지
- 요청마다 2~5초 랜덤 딜레이
- 실제 Chrome User-Agent 사용

### 저장
- `./output/{도메인명}/` 폴더에 저장
- 도메인명은 URL에서 자동 추출

### 리포트
크롤링 완료 후 `{도메인명}_report.md` 파일 자동 생성:
- 시작/종료 시간, 소요 시간
- 총 방문 페이지 수
- 다운로드한 리소스 수 (HTML, 이미지, CSS, JS, 폰트 각각)
- 실패한 URL 목록과 에러 메시지
- 총 다운로드 용량

### 콘솔 출력
- 실시간 진행: [현재/전체] URL 표시
- 에러 발생 시 표시
- 시작/완료 명확히 표시

### 에러 처리
- 개별 페이지 실패해도 계속 진행
- 타임아웃 30초, 실패 시 1회 재시도
- 네트워크 에러는 로그 기록 후 스킵

## 실행 단계
1. package.json 생성 및 npm install
2. npx playwright install chromium
3. crawler.js 실행

## 중요
- 중간에 질문하지 말고 모든 작업 자동 완료
- 리포트에 모든 결과 상세 기록
```

## 🎯 사용 방법

### 1단계: URL 변경
위 프롬프트에서 `https://example.com`을 크롤링할 실제 사이트 URL로 변경

### 2단계: Claude CLI에 붙여넣기
변경한 프롬프트를 다른 Claude CLI 세션에 붙여넣기

### 3단계: 실행 확인
Claude가 자동으로 다음을 수행:
- ✅ package.json 생성
- ✅ 의존성 설치
- ✅ Playwright 브라우저 설치
- ✅ crawler.js 생성
- ✅ 크롤링 실행
- ✅ 리포트 생성

## 🔧 실행 후 다른 사이트 크롤링

생성된 crawler.js로 다른 사이트도 크롤링 가능:

```bash
# 예시 1
node crawler.js https://another-site.com

# 예시 2
node crawler.js https://docs.example.org

# 예시 3
node crawler.js https://blog.mysite.net
```

각 도메인별로 별도 폴더와 리포트가 자동 생성됩니다:
- `./output/another-site.com/`
- `another-site_com_report.md`

## 📊 생성되는 파일 구조

```
프로젝트폴더/

├── crawler.js
├── {도메인명}_report.md          # 예: www_example_com_report.md
├── output/
│   └── {도메인명}/               # 예: www.example.com/
│       ├── index.html
│       ├── about/

│       ├── images/
│       │   ├── logo.png
│       │   └── banner.jpg
│       ├── css/
│       │   └── style.css
│       └── js/
│           └── main.js
└── node_modules/
```

## ⚙️ 설정 커스터마이징

생성된 `crawler.js` 상단의 CONFIG 수정:

```javascript
const CONFIG = {
  maxPages: 1000,        // 최대 페이지 수
  timeout: 30000,        // 타임아웃 (밀리초)
  minDelay: 2000,        // 최소 딜레이
  maxDelay: 5000,        // 최대 딜레이
  retryAttempts: 1       // 재시도 횟수
};
```

## ⚠️ 주의사항

1. **법적 준수**: 크롤링이 허용된 사이트만 사용
2. **robots.txt**: 사이트의 크롤링 정책 확인
3. **서버 부하**: 딜레이로 서버 부담 최소화
4. **저작권**: 크롤링한 콘텐츠의 적법한 사용
5. **개인정보**: 개인정보 포함 페이지 크롤링 금지

## 🐛 문제 해결

### 타임아웃 에러
```javascript
timeout: 60000  // 30초 → 60초로 증가
```

### 메모리 부족
```javascript
maxPages: 500   // 1000 → 500으로 감소
```

### 한글 깨짐 (Windows)
```bash
chcp 65001  # 터미널을 UTF-8로 설정
```
