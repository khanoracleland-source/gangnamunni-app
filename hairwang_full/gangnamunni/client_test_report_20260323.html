구분항목현재 상태필요 작업우선순위
A 하단 탭 5 → 4 조정 현재 5탭 (홈/병원/이벤트/후기/마이) 클라이언트 확인 필요: 어떤 탭을 제거할지 결정 중
B 지역+시술 복합 필터 검색바 키워드 검색 + 지역 필터 별도 동작 검색바에 지역/시술 드롭다운 결합 중
C 병원 정렬 옵션 세분화 is_featured 기본 정렬 거리순/별점순/후기많은순/가격순 추가 중
D 커뮤니티 게시판 CRUD 커뮤니티 페이지 존재, 기본 표시 글쓰기/수정/삭제/댓글 CRUD 보강 하

위 4개 항목에 대해 클라이언트의 구체적인 요구사항 확인 후 즉시 개발 진행 예정입니다.
특히 A항목(하단 탭 조정)은 어떤 탭을 남길지 클라이언트 결정이 필요합니다.
