크론잡 동작 (cron_cpv_daily.php)
5 0 * * * — 매일 00:05에 자동 실행 | 로그: /var/log/cpv_cron.log
1
일일 집계 (Daily Aggregation)

어제의 gangnamunni_cpv_logs 데이터를 병원별로 집계하여 gangnamunni_cpv_daily_stats에 INSERT/UPDATE

집계 항목: 총 조회수, 과금 조회수, 유니크 방문자, 총 금액, 평균 단가

2
잔액 부족 알림 (Low Balance Alert)

설정 임계값(cpv_low_balance_threshold) 이하인 병원 → gangnamunni_admin_notifications에 알림 생성

관리자가 알림 센터에서 확인 가능

3
로그 정리 (Log Purge)

cpv_log_retention_days (기본 90일) 이전 CPV 로그 레코드 일괄 DELETE

디스크 공간 절약 + 쿼리 성능 유지

4
거래 정리 (Transaction Purge)

transaction_retention_days (기본 365일) 이전 거래 레코드 일괄 DELETE

장기 미사용 거래 자동 정리

5
자동 해제 (Auto Unpause)

충전 후 잔액 > 0 인데 여전히 paused 상태인 지갑 → active로 자동 복구

병원 관리자가 충전 후 수동 해제를 잊어도 자동으로 서비스 재개

서버 crontab 등록 현황 (3건): 
*/1 * * * *  cron_sync.sh          # HMS↔강남언니 동기화
 0  3 * * *  cron_purge_trash.php   # 메일 휴지통 정리
 5  0 * * *  cron_cpv_daily.php     # CPV 일일 집계 + 알림 + 정리
