미확인

이 기능은 무엇인가요?

서울미녀에 입점한 각 병원마다 "광고비 전용 전자지갑"이 하나씩 자동으로 만들어집니다.

병원이 광고를 하려면, 이 지갑에 먼저 돈(포인트)을 충전해 두어야 합니다. 사용자가 해당 병원의 상세 페이지를 볼 때마다, 지갑에서 광고비(CPV)가 자동으로 차감됩니다.

쉬운 비유

교통카드와 같은 원리입니다. 버스를 타기 전에 교통카드에 돈을 충전해 두면, 버스를 탈 때마다 자동으로 요금이 빠져나갑니다. 잔액이 없으면 탈 수 없듯이, 지갑 잔액이 0원이면 광고가 자동으로 중단됩니다.

실제 사용 예시

  • A성형외과가 서울미녀에 입점 → 자동으로 "A성형외과 광고 지갑" 생성 (잔액 0원)
  • A성형외과가 50만원 충전 → 지갑 잔액 500,000원
  • 사용자가 A성형외과 상세 페이지 조회 → CPV 200원 차감 → 잔액 499,800원
  • 지갑 잔액 0원 도달 → A성형외과 광고 자동 중단
  • 재충전하면 광고 자동 재개

왜 필요한가요?

이것이 서울미녀의 핵심 수익 모델입니다. 병원은 광고비를 선불 충전하고, 사용자가 볼 때마다 과금됩니다. 강남언니와 동일한 수익 구조이며, 이 지갑이 없으면 과금 자체가 불가능합니다.

상세 사양:
  • 병원 1개 = 지갑 1개 (자동 생성, 1:1 매핑)
  • 잔액 단위: 원 (₩)
  • 지갑에서 실시간으로 확인 가능: 현재 잔액 / 총 충전액 / 총 소진액
  • 잔액이 0원이 되면 해당 병원의 모든 유료 광고 노출이 자동 중단

결제가 완료되면 지갑에 포인트가 즉시 충전되고, 그때부터 광고가 노출됩니다.

쉬운 비유

네이버 검색광고 충전과 같습니다. 네이버 광고도 광고비를 먼저 충전해 놓으면, 클릭이 발생할 때마다 차감되는 방식입니다.

실제 사용 예시

  • 병원 관리자가 "충전하기" 버튼 클릭
  • 충전 금액 선택: 10만원 / 30만원 / 50만원 / 100만원 또는 직접 입력
  • 결제 수단 선택 (신용카드 / 실시간 계좌이체 / 가상계좌)
  • PG사(이니시스) 결제 창에서 결제 완료
  • 지갑에 포인트 즉시 반영 + 영수증 발급
상세 사양:
  • 결제 수단: 신용카드, 실시간 계좌이체, 가상계좌
  • 부가세 10% 별도 (공급가 + VAT 분리 표시)
  • 충전 내역 및 영수증 조회 가능
  • 기존 이니시스 PG 연동 활용

쉬운 비유

카페에서 음료를 받았을 때만 결제되는 것과 같습니다. 주문 후 취소하면 돈이 안 빠지듯, 페이지를 다 보지 않으면 과금되지 않습니다.

과금되는 경우 vs 안 되는 경우

  • 과금 O: 사용자가 "A성형외과" 클릭 → 상세 페이지 완전히 열림 → CPV 200원 차감
  • 과금 X: 사용자가 "A성형외과" 클릭 → 로딩 중 뒤로가기 → 과금 안 됨
  • 과금 X: 사용자가 목록에서 병원 이름만 봄 (클릭 안 함) → 과금 안 됨
과금 대상 페이지 (3종):
  • 병원 상세 페이지
  • 의사 프로필 페이지
  • 이벤트 상세 페이지

  • 상담 신청 버튼 클릭 → 추가 과금 없음

  • 전화 걸기 → 추가 과금 없음
  • 실제 내원(방문) → 추가 과금 없음
  • 후기 작성, 찜하기, 공유 등 → 모두 추가 과금 없음

어뷰징 방지 — 동일 유저 중복 과금 차단 핵심 신규
미확인

이 기능은 무엇인가요?

같은 사람이 같은 페이지를 여러 번 새로고침하거나 반복 방문해도 일정 시간 내에는 1회만 과금되어, 광고주(병원)의 광고비를 보호합니다.

쉬운 비유

지하철 환승 시간(30분)과 같습니다. 30분 안에 다시 찍으면 요금이 빠지지 않듯, 30분 안에 같은 페이지를 다시 보면 과금되지 않습니다.

왜 필요한가요?

이 기능이 없으면, 경쟁 병원이 악의적으로 상대 병원 페이지를 수백 번 클릭하여 광고비를 고갈시키는 "클릭 폭탄" 공격이 가능합니다. 광고주 보호를 위해 필수적인 기능입니다.

어뷰징 방지 규칙 5가지

  • 시간 중복 차단 (30분): 같은 사람이 같은 페이지를 30분 내 재방문 → 1회만 과금
  • 일일 한도 (10회): 같은 사람이 같은 병원을 하루 10번 이상 조회 → 초과분 과금 안 함
  • 속도 제한: 같은 IP에서 1분 내 5페이지 이상 연속 조회 → 봇 의심, 과금 안 함
  • 봇/크롤러 차단: 구글봇 등 자동 프로그램 접속 → 과금 안 함
  • 자기 조회 제외: 병원 관리자가 자기 병원 페이지 확인 → 과금 안 함

미확인

이 기능은 무엇인가요?

사용자가 어떤 검색어(키워드)를 통해 병원 페이지에 들어왔느냐에 따라 과금 단가가 달라집니다. 인기 키워드로 유입된 조회는 비싸고, 비인기 키워드는 저렴합니다.

쉬운 비유

네이버 검색광고 키워드 입찰과 같습니다. "강남 성형외과"는 비싸고, "지방 피부과"는 저렴한 것처럼, 경쟁이 치열한 키워드일수록 CPV가 높습니다.

단가 예시

  • "눈성형" 키워드로 유입: 기본 100원 × 가중치 2.0 = 200원/View
  • "코성형" 키워드로 유입: 기본 100원 × 가중치 1.8 = 180원/View
  • "일반 검색" 유입: 기본 100원 × 가중치 1.0 = 100원/View
  • "기타/비인기" 키워드: 기본 100원 × 가중치 0.5 = 50원/View

쉬운 비유

  • 최고 관리자가 시술 카테고리별 가중치를 자유롭게 조정
  • 예: 안면윤곽 ×2.5, 눈성형 ×2.0, 보톡스 ×0.8 등

쉬운 비유

백화점 세일 기간에 매장 임대료가 오르는 것과 같습니다. 사람이 몰리는 시즌에는 단가가 올라갑니다.

  • 이벤트 진행 중: 가중치 ×1.5 (50% 할증)

  • 최고 관리자가 할증 비율 조정 가능

미확인

이 기능은 무엇인가요?

병원 관리자가 "오늘 하루 광고비를 최대 10만원까지만 쓰겠다"고 직접 상한선을 설정하는 기능입니다. 설정한 금액에 도달하면 당일 광고가 자동 중단되어 예산을 보호합니다.

쉬운 비유

신용카드 일일 사용 한도와 같습니다. "오늘은 10만원까지만"이라고 설정하면, 그 이상 결제되지 않습니다.

실제 사용 예시

  • A성형외과가 일일 캡을 100,000원으로 설정
  • 오전에 CPV가 누적되어 오후 3시에 99,800원 소진
  • 다음 조회 시 100,000원 초과 → 당일 광고 자동 중단
  • 다음 날 00:00에 자동 리셋 → 광고 재개
  • 병원 관리자가 직접 금액 입력 (0원 = 무제한)
  • 소진률 실시간 프로그레스 바 표시
  • 언제든 변경 가능

이 기능은 무엇인가요?

충전된 포인트가 모두 소진(0원)되면, 사용자 앱/웹에서 해당 병원의 유료 광고 영역이 자동으로 사라집니다. 일반 검색 결과에는 그대로 노출됩니다.

쉬운 비유

교통카드 잔액이 0원이면 버스를 탈 수 없는 것과 같습니다. 재충전하면 즉시 다시 탈 수 있습니다.

중단 vs 유지 영역

  • 중단: 배너 광고, 인피드 광고, 추천 병원 영역 (유료)
  • 유지: 일반 병원 검색 결과, 기본 병원 프로필 (무료)
  • 재충전 시 즉시 광고 재개

이 기능은 무엇인가요?

잔액이 약 3일치 예산 이하로 떨어지면, 병원 관리자에게 "곧 잔액이 소진됩니다. 충전해 주세요"라는 알림을 자동 발송합니다.

쉬운 비유

자동차 연료 경고등과 같습니다. 기름이 완전히 떨어지기 전에 미리 경고해서 주유소에 갈 시간을 줍니다.

  • 병원이 직접 알림 기준 금액을 설정 가능 (예: "잔액 5만원 이하 시 알림", "잔액 10만원 이하 시 알림" 등 자유 지정)
  • 알림 방식: 관리자 대시보드 알림 + 이메일(선택)
