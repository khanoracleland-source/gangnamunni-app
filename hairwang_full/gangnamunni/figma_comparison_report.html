피그마 원본 디자인을 기반으로 서울미녀 웹사이트의 전체 UI를 리팩토링 완료했습니다. 주요 변경 사항은 브랜드 컬러 통일(#AE1932), 폰트 표준화(Noto Sans KR), 하단 네비게이션 구조 변경(5탭 → 4탭), 플랫 디자인 적용(그림자 제거, sharp corners) 등입니다.

주요 디자인 변경 사항

# 항목 변경 전 변경 후 (피그마 기준) 상태
1 브랜드 컬러 #7C3AED / #D32F2F 혼용 #AE1932 통일 완료
2 폰트 시스템 폰트 혼용 Noto Sans KR 전체 적용 완료
3 하단 네비게이션 5탭, Bootstrap 아이콘, 60px 4탭 (홈/시술/커뮤니티/마이), 커스텀 25x25 PNG, 77px 완료
4 시술 테이블 둥근 모서리, 그림자 #F1F1F1 헤더, #D5D5D5 보더, 16px 폰트, sharp corners 완료
5 이벤트 카드 border-radius: 12px, box-shadow sharp corners, 그림자 제거, flat 디자인 완료
6 정렬 칩 둥근 pill 형태, 14px radius 5px 정사각, 18px, #000/#AAA 컬러 완료
7 커뮤니티 탭 밑줄 스타일 활성 탭 filled 스타일, #AE1932 활성 배경 완료
8 마이페이지 #FFFFFF 배경, 작은 아바타 #F8F8F8 배경, 50x50 회색 아바타, 18px 메뉴 완료
9 검색바 회색 배경, 둥근 모서리 1px #1A0000 테두리, #FFFFFF 배경 완료
10 지역 선택 버튼 텍스트 링크 / 드롭다운 #1A0000 bg, radius 30, 18px 700 폰트 완료
