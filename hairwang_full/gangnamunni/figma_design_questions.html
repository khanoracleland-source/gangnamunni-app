필수 Q1-1. 시술 카테고리 선택 방식 — 싱글 vs 멀티?

홈 화면의 시술명(세미지FLX, 텐써마 등)을 탭할 때:

A) 싱글 셀렉트 1개 탭 → 해당 시술 병원 목록으로 이동 ★ 강남언니·바비톡·여신티켓 모두 이 방식
B) 멀티 셀렉트 여러 개 선택 → "검색" 버튼으로 결과 확인 (업계 미사용)
C) 대분류→소분류 확장 "리프팅" 탭 → 하위 펼침 → 소분류 탭 시 이동
필수 Q1-2. 시술명 탭 시 이동 페이지는?

예: "텐써마"를 탭하면 어디로?

A) 병원 목록 (해당 시술 필터 적용)
B) 가격 비교 페이지
C) 시술 상세 정보 + 병원 목록
D) 이벤트 목록 (할인 이벤트)
중요 Q1-3. 대분류(왼쪽)와 소분류(오른쪽)의 관계
A) 대분류 탭 → 소분류 목록 변경 (탭 네비게이션)
B) 대분류도 탭 가능한 링크 (전체 카테고리 페이지 이동)
C) 대분류는 단순 레이블 (탭 불가), 소분류만 탭 가능

A) 현재 6개만 고정

C) 좌우 스와이프로 더 많은 카테고리
