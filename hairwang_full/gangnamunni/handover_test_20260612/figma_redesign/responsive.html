🔧 반응형 전환 전략 — Fluid Typography (clamp)

clamp(최소, 기준vw, 최대): 화면 폭에 따라 폰트가 부드럽게 스케일되되 너무 작거나 크지 않게 상·하한을 둠. (390px 디자인 기준)

현재 (고정)제안 (반응형)
font-size:10px ×19→font-size:clamp(9px, 2.6vw, 11px)
font-size:11px ×45→font-size:clamp(10px, 2.9vw, 12px)
font-size:12px ×65→font-size:clamp(11px, 3.1vw, 13px)
font-size:13px ×68→font-size:clamp(12px, 3.4vw, 14px)
font-size:14px ×46→font-size:clamp(13px, 3.7vw, 15px)
font-size:15px ×28→font-size:clamp(14px, 4.0vw, 16px)
font-size:16px→font-size:clamp(15px, 4.3vw, 17px)
font-size:18px ×15→font-size:clamp(16px, 4.8vw, 19px)
font-size:20px→font-size:clamp(18px, 5.3vw, 21px)
font-size:24px→font-size:clamp(20px, 6.4vw, 25px)
✅ 이렇게 하면 작은 폰에선 살짝 작게, 큰 화면/태블릿에선 살짝 크게 — 모든 기기에서 균형있게 보이고 Figma 비율에 가깝게 유지됩니다.

⚙️ 적용 방법 (2가지)

방법 A — 토큰 CSS 변수 (권장, 한 곳에서 관리)

:root{
  --fs-10: clamp(9px, 2.6vw, 11px);
  --fs-12: clamp(11px, 3.1vw, 13px);
  --fs-13: clamp(12px, 3.4vw, 14px);
  --fs-14: clamp(13px, 3.7vw, 15px);
  --fs-15: clamp(14px, 4.0vw, 16px);
  --fs-18: clamp(16px, 4.8vw, 19px);
}
/* 사용: font-size: var(--fs-13);  (기존 13px 자리) */

방법 B — 루트 폰트 스케일 + rem 전환

html{ font-size: clamp(14px, 4.1vw, 17px); }  /* 1rem 기준 */
/* 12px → 0.857rem, 13px → 0.93rem, 14px → 1rem ... */
⚠️ 주의: 기존 하드코딩 px를 일괄 치환 시 레이아웃이 흔들릴 수 있어 핵심 텍스트(제목·가격·본문)부터 단계적으로. 고정 width:px는 max-width:100% 또는 %로.
