3Ralph 루프 — 끝까지 자율 E2E 테스트 (웹+Android+iOS)

로그인부터 전체 기능을 자율 테스트 → 스크린샷·동영상 → HTML 리포트, 전부 통과까지 반복.

Claude Code (오케스트레이터 = Ralph 루프) ├── figma MCP → 디자인 실측 적용 ├── playwright MCP → 웹 로그인~전체 플로우 (video/screenshot/trace) └── mobile-mcp → Android/iOS 앱 (실기기, 캡처) ↓ HTML 리포트 (동영상·스크린샷·trace 임베드) → 전부 통과 시 success.flag

도구 스택

🎨 Framelink Figma MCP

GLips/figma-context-mcp · API 키만으로 디자인 토큰/레이아웃 실측 추출. 공식 Dev Mode seat 불필요.

🌐 Playwright (MCP)

웹 E2E · video/screenshot/trace 자동 캡처 + HTML 리포트 내장.

📱 mobile-mcp

mobile-next · iOS/Android/시뮬레이터 단일 인터페이스, GitHub 5k+★. 실기기 캡처.

🔁 Ralph 루프

동일 프롬프트를 통과까지 반복하는 쉘 패턴. ralph-loop.ps1.

실행 (3줄)

# 1) MCP 등록 (.mcp.json: figma + playwright + mobile-mcp)
cp _redesign_kit/mcp.json .mcp.json
# 2) Ralph 루프 — 전부 통과까지 자율 반복
pwsh _redesign_kit/ralph-loop.ps1 -MaxLoops 30
# 3) 리포트 확인 (동영상·스크린샷 임베드)
npx playwright show-report
루프 로직: ① 직전 실패 분석 → ② 테스트 작성/디자인 보정 → ③ 웹+모바일 실행(캡처) → ④ 실패면 수정 후 재실행 → ⑤ 전부 통과 시 report/success.flag 생성하고 종료.
⚠️ Ralph 루프 내 서버 PHP/DB 로직 임의 수정 금지(테스트·디자인만). 명백한 구현 버그는 보고만.
