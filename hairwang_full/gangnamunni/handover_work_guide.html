🔁 인수자(받는 쪽) 복원 절차

  1. ①소스 압축 풀기 → 웹 루트에 배치
  2. composer install + npm install (vendor/node_modules 복원)
  3. ②DB import: gunzip < hms_saas.sql.gz | mysql -uroot -p hms_saas (hairwang도 동일)
  4. .env의 DB접속정보를 자기 서버에 맞게 수정
  5. php artisan storage:link (storage 심볼릭 재생성)
  6. Apache vhost 배치 + 도메인/SSL 설정
  7. ③앱소스는 Mac에서 빌드 (Flutter 3.35.4)
