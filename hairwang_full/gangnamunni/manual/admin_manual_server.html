관리자 시스템 개요

서울미녀 관리자 패널은 강남언니 프론트엔드의 모든 콘텐츠와 설정을 관리합니다. Bootstrap 5.3 기반 반응형 UI에 다크/라이트 모드를 지원하며, 역할 기반 접근 제어(RBAC)로 보안을 강화했습니다.

01 대시보드 (dashboard.php)

관리자 로그인 후 첫 화면입니다. 전체 시스템 현황을 한눈에 파악할 수 있습니다.

대시보드 화면 (dashboard.php)
주요 구성 요소
  • 통계 카드 (4개): 전체 병원 수, 등록 회원 수, 오늘 예약, 신규 후기
  • 외부 링크 영역: HMS 관리자, 메일 서버, 서버 관리 등 바로가기
  • 관리 메뉴 그리드 (12개): 주요 관리 기능 아이콘 그리드
  • 최근 활동: 최근 후기, 회원가입, 예약 등 활동 로그
팁: 대시보드 통계 카드는 실시간으로 DB를 조회합니다. 캐시 초기화 버튼으로 최신 데이터를 강제 갱신할 수 있습니다.

02 병원/이미지 관리 (admin_hospital_images.php)

병원 정보 CRUD 및 각 병원별 이미지(사진) 관리를 위한 아코디언 기반 인터페이스입니다.

병원/이미지 관리 화면 (admin_hospital_images.php)
기능 목록
  • 병원 CRUD: 병원 이름, 주소, 전화번호, 진료과 등 기본 정보 관리
  • 아코디언 UI: 각 병원을 클릭하면 상세 정보와 이미지 목록 표시
  • 이미지 업로드: 드래그&드롭 + 파일 선택 다중 업로드 지원
  • 이미지 미리보기: 썸네일 그리드로 업로드된 이미지 확인
  • 일괄 삭제: 체크박스 선택 후 일괄 이미지 삭제
  • HMS 연동: HMS hospital_type과 자동 동기화

03 후기 관리 (admin_reviews.php)

병원 후기 보기, 편집, 승인/거부 및 일괄 처리 기능을 제공합니다.

후기 관리 화면 (admin_reviews.php)
기능 목록
  • 후기 목록: 검색, 필터(병원, 상태, 기간), 정렬 기능
  • 상태 관리: 대기(pending), 승인(approved), 거부(rejected) 상태 전환
  • 편집 모달: 인라인 편집 모달로 후기 내용 수정
  • 일괄 처리: 체크박스 선택 후 일괄 승인/거부/삭제
  • AI 검증: AI 품질 점수 및 스팸 탐지 결과 표시
  • Quill 에디터 연동: 리치 텍스트 후기 에디터 (이미지 포함)

04 카테고리 관리 (admin_categories.php)

시술 카테고리를 관리합니다. SVG 아이콘과 이모지를 지원하는 피커 UI를 제공합니다.

카테고리 관리 화면 (admin_categories.php)
기능 목록
  • 카테고리 CRUD: 이름, 설명, 아이콘, 활성 상태 관리
  • SVG 아이콘 피커: 썸네일 그리드에서 SVG 아이콘 선택
  • 이모지 피커: 8탭 264종 대형 이모지 선택 UI
  • 활성/비활성 토글: 카테고리별 즉시 활성 상태 변경
  • HMS 연동: hospital_type 테이블과 양방향 동기화 (12건)
  • 정렬: 드래그&드롭으로 카테고리 순서 변경
팁: category_icons.php에서 SVG 아이콘이 흰색 원형 배경 위에 렌더링됩니다. 새 아이콘 추가 시 이 파일도 함께 수정하세요.

12 부관리자 RBAC (admin_admins.php)

부관리자 계정 관리 및 역할 기반 접근 제어(RBAC) 시스템입니다.

역할 체계
역할코드권한 범위
최고관리자super_admin모든 메뉴 접근 + 부관리자 관리
관리자admin대부분 메뉴 접근 (부관리자 관리 제외)
편집자editor콘텐츠 관리 메뉴만 접근
뷰어viewer읽기 전용 (대시보드, 통계 조회)
기능
  • 계정 생성: 아이디, 비밀번호(bcrypt), 역할, 이름 설정
  • 권한 설정: 메뉴별 접근 권한 체크박스 관리
  • 활동 로그: 관리자 행동 로깅
  • 기본 계정: admin / admin123 (최고관리자)

13 자동 매뉴얼 캡처 (admin_auto_manual.php)

Playwright 기반 자동 스크린샷 캡처 시스템으로, 매뉴얼용 화면 캡처를 자동화합니다.

아키텍처
구성요소기술설명
엔진 서버Node.js Express (port 3100)Playwright 캡처 API 서버
브라우저Playwright Chromium헤드리스 브라우저
주석 도구markerjs2 2.32.7캡처 이미지에 주석 추가
systemdauto-manual-engine서비스 자동 시작/관리
ApacheProxyPass/auto-manual-api/ -> localhost:3100
사용 방법
  1. 캡처 세션 생성 - 대상 URL과 캡처 옵션 설정
  2. 자동 캡처 실행 - 페이지 로딩 후 자동 스크린샷
  3. 주석 추가 - markerjs2로 화살표, 텍스트, 하이라이트 추가
  4. 결과 저장 - 캡처 이미지 DB 저장 및 매뉴얼 생성

14 메일 관리 (admin_mail.php)

Gmail 스타일 3컬럼 레이아웃의 메일 관리 시스템 v4입니다.

메일 관리 화면 (admin_mail_accounts.php)
기능 목록
  • 3컬럼 레이아웃: 폴더 목록 | 메일 목록 | 메일 내용
  • 작성 오버레이: 1050px 작성 오버레이 + 전체화면 모드
  • IMAP 수신: SSL 993포트 IMAP 수신 (폴더: INBOX, Sent, Drafts, Junk, Trash, Archive)
  • SMTP 발송: STARTTLS 587포트 SMTP 발송 + 첨부파일(multipart/mixed)
  • 인라인 이미지: 재귀 MIME 파싱, CID -> data URI 자동 변환
  • 상용구 관리: JSON 기반 상용구 CRUD, 작성 시 삽입
  • 서명 관리: 계정별 서명, 포함/미포함 토글
  • 일괄 처리: 전체선택/선택삭제/읽음/안읽음 일괄 변경
AJAX 액션
