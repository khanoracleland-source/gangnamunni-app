Phase A AI 인프라

AI 기능의 기반이 되는 인프라 레이어입니다. API 키 관리, 암호화, 멀티 프로바이더 전환을 담당합니다.

핵심 구성요소
API 키 관리
  • AES-256-CBC 암호화 저장
  • 키 마스킹 표시 (sk-****...1234)
  • 키 유효성 실시간 검증
  • 복호화 조회 (관리자 전용)
멀티 프로바이더
  • OpenAI / Claude / Gemini 동적 전환
  • 장애 시 자동 폴백 (fallback)
  • 프로바이더별 요금 추적
  • 응답 시간 모니터링
DB 테이블
-- ai_api_keys: AI API 키 저장 (암호화)
CREATE TABLE ai_api_keys (
  id INT PRIMARY KEY AUTO_INCREMENT,
  provider VARCHAR(50),        -- openai, claude, gemini
  key_name VARCHAR(100),       -- 표시용 이름
  encrypted_key TEXT,          -- AES-256-CBC 암호화된 키
  is_active TINYINT DEFAULT 1,
  created_at DATETIME,
  updated_at DATETIME
);

-- ai_usage_logs: API 사용량 로깅
CREATE TABLE ai_usage_logs (
  id INT PRIMARY KEY AUTO_INCREMENT,
  provider VARCHAR(50),
  action VARCHAR(100),         -- review_check, ad_check, suggest
  tokens_used INT,
  cost_usd DECIMAL(10,6),
  response_ms INT,
  created_at DATETIME
);

Phase D AI 설정 관리

관리자 UI에서 AI 기능의 전체 설정을 관리합니다. 파일: admin_ai_settings.php

AI 설정 관리 화면 (admin_ai_settings.php)
설정 항목

  • 프로바이더별 API 키 등록 (AES-256-CBC 암호화 저장)
  • 키 유효성 실시간 검증 버튼
  • 마스킹된 키 표시 (sk-****...1234)
  • 활성/비활성 토글

  • 자동 승인 임계 점수 (기본: 80점)
  • 자동 보류 임계 점수 (기본: 60점)
  • 후기 검증 활성화/비활성화
  • 광고 검증 활성화/비활성화

  • 일일 API 호출 한도 (기본: 1,000회)
  • 월간 비용 한도 (기본: $100)
  • 한도 도달 시 이메일 알림
  • 한도 초과 시 동작 설정 (중지/경고만)

  • 일별/주별/월별 API 호출 차트
  • 프로바이더별 사용 비율
  • 기능별 사용 분포 (검증/제안/이미지 생성)
  • 비용 추이 그래프

Phase E 작성 도우미

후기 작성 중 AI가 실시간으로 문장 제안, 자동완성, 표현 개선을 도와줍니다.

기능
실시간 제안 패널

후기 에디터 옆에 AI 제안 패널이 표시됩니다. 입력한 내용을 분석하여 추가할 수 있는 문장을 제안합니다.

문장 자동완성

입력 중 3개의 자동완성 후보를 생성합니다. Tab 키로 선택하여 삽입할 수 있습니다.

표현 개선

작성된 문장을 분석하여 더 자연스럽고 구체적인 표현으로 개선을 제안합니다.

API 호출
// POST /gangnamunni/api/ai_suggest.php
{
  "context": "눈 수술 후기를 작성하고 있음",
  "current_text": "강남 OO성형외과에서 눈 수술을 받았습니다.",
  "action": "suggest_next"  // suggest_next | autocomplete | improve
}

// Response
{
  "suggestions": [
    "수술 전 상담에서 의사 선생님이 상세하게 설명해 주셨습니다.",
    "수술 후 붓기는 약 1주일 정도 지속되었습니다.",
    "전체적인 만족도는 매우 높습니다."
  ]
}

광고 이미지 생성

DALL-E 3을 사용하여 광고용 이미지를 자동으로 생성합니다.

사용 방법
  1. 프롬프트 입력: 원하는 이미지 설명을 자연어로 입력 (한국어 지원)
  2. 옵션 설정: 크기(1024x1024), 스타일(자연/생생), 품질(표준/HD) 선택
  3. 생성 실행: "이미지 생성" 버튼 클릭 (약 8~15초 소요)
  4. 결과 확인: 생성된 이미지 미리보기, 다운로드 또는 광고에 즉시 적용
비용: DALL-E 3 이미지 1장 생성 비용은 약 $0.04 (표준) ~ $0.08 (HD)입니다. 월간 비용 한도 설정으로 관리하세요.
