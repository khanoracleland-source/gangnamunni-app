보안 안내

AES-256-CBC 암호화 저장

모든 API 키는 AES-256-CBC 알고리즘으로 암호화되어 데이터베이스에 저장됩니다. 평문 키는 절대 DB에 저장되지 않습니다.

마스킹 표시

관리자 UI에서 API 키는 마스킹 처리되어 표시됩니다.
sk-ant-***...***GQA

Super Admin 전용

API 키의 등록, 수정, 삭제는 Super Admin 권한을 가진 관리자만 수행할 수 있습니다. 일반 관리자는 키 관리에 접근할 수 없습니다.

유출 시 즉시 대응

API 키가 유출된 경우, 각 프로바이더 콘솔에서 즉시 키를 삭제(Revoke)하고 새 키를 발급받아 등록하세요.

DB 평문 저장 금지

데이터베이스에는 암호화된 키 값만 저장됩니다. 서버 침해 시에도 키 원문을 알 수 없어 안전합니다.

사용량 모니터링

모든 API 호출은 로깅되며, 비정상적인 사용 패턴이 감지되면 자동으로 관리자에게 알림이 발송됩니다.

API 키 유출 시 긴급 조치 순서:
  1. 해당 프로바이더 콘솔에서 즉시 키 삭제 (Revoke)
  2. 새 API 키 발급
  3. Seoul Beauty 관리자 페이지에서 기존 키 삭제 후 새 키 등록
  4. 사용량 로그를 확인하여 비정상 사용 여부 점검

자주 묻는 질문 (FAQ)

Anthropic: API 키 자체에는 만료 기간이 없습니다. 다만 결제 잔액이 소진되면 API 호출이 거부됩니다. 크레딧 충전으로 해결할 수 있습니다.

OpenAI: API 키 자체에는 만료 기간이 없습니다. 결제 수단이 유효하고 사용 한도 내에 있으면 계속 사용 가능합니다. 무료 크레딧은 일정 기간 후 만료될 수 있으니, 유료 결제로 전환하는 것을 권장합니다.

프로바이더 자체 한도: Anthropic과 OpenAI 모두 결제 페이지에서 월간 사용 한도를 설정할 수 있습니다. 한도에 도달하면 API 호출이 자동으로 차단됩니다.

Seoul Beauty 내부 한도: 관리자 설정 페이지(admin_ai_settings.php)에서 일일 API 호출 횟수 한도와 월간 비용 한도를 설정할 수 있습니다. 한도에 도달하면 AI 기능이 일시 중지되고 관리자에게 이메일 알림이 발송됩니다.

아니요, 비용이 발생하지 않습니다. AI 기능은 API 호출 시에만 과금됩니다. 관리자 설정에서 AI 검증을 비활성화하면 API 호출이 발생하지 않으므로 비용도 발생하지 않습니다. API 키를 등록해 두더라도 호출하지 않으면 과금되지 않습니다.

즉시 다음 조치를 수행하세요:

  1. 해당 프로바이더 콘솔에 로그인하여 즉시 키를 삭제(Revoke)합니다.
  2. 새 API 키를 발급받습니다.
  3. Seoul Beauty AI 설정 페이지에서 기존 키를 삭제하고 새 키를 등록합니다.
  4. 프로바이더의 사용량 대시보드에서 비정상적인 사용이 없었는지 확인합니다.

네, 가능합니다. Seoul Beauty는 멀티 프로바이더 시스템을 지원하여 여러 개의 API 키를 등록할 수 있습니다.

  • 우선순위 설정: 각 키에 우선순위를 지정하면, 우선순위가 높은 키부터 사용됩니다.
  • 자동 폴백: 우선순위 1번 키에 장애가 발생하면 자동으로 2번 키로 전환됩니다.
  • 용도별 분리: 텍스트 분석용(Anthropic)과 이미지 생성용(OpenAI DALL-E)을 별도로 관리할 수 있습니다.

토큰(Token)은 AI 모델이 텍스트를 처리하는 기본 단위입니다. 한국어의 경우 대략 1글자 = 2~3 토큰 정도입니다.

예시:
"안녕하세요" → 약 5~7 토큰
"서울 강남 성형외과 후기입니다" → 약 15~20 토큰
일반 후기 1건 (~200자) → 약 400~600 토큰

1M(100만) 토큰 = 약 50만 자 한국어 텍스트. 일반적인 후기 검증은 건당 약 800 토큰으로, 1M 토큰이면 약 1,250건을 처리할 수 있습니다.

Anthropic: 신규 가입 시 일부 무료 크레딧이 제공될 수 있습니다. 다만 금액이 적으므로 테스트 용도로만 사용하는 것을 권장합니다.

OpenAI: 일부 신규 계정에 $5 무료 크레딧이 제공됩니다 (가입 시기에 따라 다름). 무료 크레딧은 일정 기간 후 만료됩니다.

Google Gemini: 추후 지원 예정이며, Google Cloud의 무료 등급(free tier)을 활용할 수 있을 것으로 기대됩니다.
