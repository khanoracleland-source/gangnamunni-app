관리자 시스템 개요

서울미녀 관리자 패널은 서울미녀 프론트엔드의 모든 콘텐츠와 설정을 관리합니다. Bootstrap 5.3 기반 반응형 UI에 다크/라이트 모드를 지원하며, 역할 기반 접근 제어(RBAC)로 보안을 강화했습니다.

NEW 페이지 설명 배너 시스템 (2026-02-26)

모든 관리 페이지 상단에 해당 페이지의 기능을 설명하는 배너가 자동으로 표시됩니다. 개별 페이지 수정 없이 admin_header.php의 $menu_descriptions 배열만으로 관리됩니다.

동작 원리
  1. 각 페이지에서 $admin_current = 'menu_key'를 설정합니다.
  2. admin_header.php가 $menu_descriptions[$admin_current]를 자동으로 조회합니다.
  3. 매칭되는 설명이 있으면 .page-desc-banner 영역에 아이콘 + 제목 + 설명을 렌더링합니다.
CSS 스타일
/* 페이지 기능 설명 배너 */
.page-desc-banner {
    padding: 14px 24px;
    margin: -24px -32px 20px -32px;
    background: var(--bs-tertiary-bg);        /* 다크모드 자동 대응 */
    border-bottom: 1px solid var(--bs-border-color);
}
.page-desc-banner h5 { font-size: 15px; font-weight: 700; }

대시보드 — 전체 현황 통계 및 바로가기

05 병원이미지 (admin_hospital_images.php)

병원 이미지 관리 — 아코디언 UI, 이미지 업로드
기능 목록
  • 병원 CRUD: 병원 이름, 주소, 전화번호, 진료과 등 기본 정보 관리
  • 아코디언 UI: 각 병원을 클릭하면 상세 정보와 이미지 목록 표시
