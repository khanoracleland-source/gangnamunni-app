마법사 마법사 엔드포인트

모든 마법사는 동일한 AJAX 패턴을 사용합니다. 각 마법사 PHP 파일 내에서 $_POST['ajax_action'] 파라미터로 분기합니다.

POST admin_{type}_wizard.php 마법사 공통 AJAX (type: doctor|nurse|pharmacist|patient|staff|medicine|appointment)
ajax_action설명추가 매개변수
validate_step단계별 유효성 검증step (int), form data
save최종 저장전체 form data
search기존 데이터 검색query (string)
get_detail상세 데이터 조회id (int)
delete데이터 삭제id (int)
check_duplicate중복 확인 (이메일 등)field, value

메일 메일 엔드포인트

메일 관리의 모든 AJAX 액션은 admin_mail.php에서 action 파라미터로 분기합니다.

POST admin_mail.php
Content-Type: application/x-www-form-urlencoded
Body: action={action_name}¶m1=value1&...
action설명추가 매개변수
unread_counts폴더별 안 읽은 메일 수-
list메일 목록 조회folder, page, per_page
read메일 상세 읽기uid, folder
delete메일 삭제uid, folder
bulk_delete메일 일괄 삭제uids (JSON array), folder
bulk_seen메일 일괄 읽음 표시uids, folder
toggle_seen읽음/안읽음 토글uid, folder
send메일 발송to, subject, body, cc, bcc, attachments
get_signature서명 조회account
save_signature서명 저장account, signature
get_templates상용구 목록-
save_template상용구 저장name, content, id (수정시)
delete_template상용구 삭제id
set_per_page페이지당 건수 설정per_page (10|20|50|100)
