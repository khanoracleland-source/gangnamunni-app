제1장 시스템 개요

Seoul Beauty(서울미녀)는 의료 미용 플랫폼으로, HMS(Hospital Management System)를 기반으로 한국형 의료 미용 서비스에 최적화된 통합 시스템입니다. 병원 관리, 환자 예약, 후기 관리, AI 기반 콘텐츠 검수, SSO 통합 로그인 등 종합적인 기능을 제공합니다.

매 1분마다 cron_sync.sh가 실행되어 4단계 동기화를 수행합니다.

단계방향내용파일

4단계양방향hospital_type - categories 매핑sync_hospital_type.php

1.7 SSO 통합 로그인

3개 시스템(HMS, Gnuboard, 강남언니) 간 Single Sign-On을 sso_tokens DB 테이블과 sb_sso_token 공유 쿠키(24시간)로 구현합니다. 어느 시스템이든 로그인하면 SSO 토큰이 발급되어 다른 시스템에서 자동 로그인됩니다.

2.4 세션 관리

모든 관리자 페이지는 $_SESSION['ad_admin_logged_in'] === true를 체크합니다. 미인증 시 dashboard.php로 리다이렉트되며, 로그아웃은 ?logout=1 파라미터로 session_destroy() 후 리다이렉트합니다. Gnuboard의 init.php와 세션 충돌을 방지하기 위해 표준 session_start()만 사용합니다.

제4장 AI 기능 가이드

Seoul Beauty는 Anthropic Claude와 OpenAI GPT를 활용한 5단계 AI 자동화 시스템을 구축하였습니다. 후기 품질 검수, 광고 컴플라이언스 체크, 글쓰기 보조 등의 기능을 제공합니다.

4.1 AI 자동화 5단계 (Phase A~E)

Phase기능설명AI 모델
Phase A후기 품질 검수AI가 후기의 진정성, 구체성, 유용성을 0~100점으로 평가Claude Haiku
Phase B광고 컴플라이언스의료 광고 법규 준수 여부 자동 체크 (규칙 기반 + AI)규칙 기반 + Claude
Phase C글쓰기 보조후기 작성 시 AI가 개선 제안 및 보완점 안내Claude Haiku
Phase D자동 카테고리 분류콘텐츠 기반 자동 시술 카테고리 태깅GPT-4o-mini
Phase E이미지 생성시술 관련 일러스트/아이콘 자동 생성DALL-E 3

4.2 지원 AI 제공업체

제공업체모델용도특징
AnthropicClaude Haiku 3.5후기 검수, 글쓰기 보조빠른 응답, 저비용, 한국어 우수
AnthropicClaude Sonnet 4고품질 분석 (예비)고품질 추론, 복잡한 분석
OpenAIGPT-4o-mini카테고리 분류다목적, JSON 출력 안정
OpenAIDALL-E 3이미지 생성고품질 일러스트 생성

4.3 후기 검수 워크플로우

단계프로세스결과
1. 제출사용자가 후기 작성 완료 후 제출pending 상태로 저장
2. 규칙 검수금칙어, 최소 글자 수, 스팸 패턴 체크규칙 위반 시 즉시 반려
3. AI 검수Claude가 진정성/구체성/유용성 평가 (0~100)62점 미만: 개선 요청
4. 제안점수 미달 시 구체적 개선 제안 제공작성자에게 제안 표시
5. 승인기준 이상 점수 + 관리자 최종 확인published 상태로 전환

4.4 광고 컴플라이언스 체크

의료 광고는 2단계로 검수합니다. 먼저 규칙 기반(금지 표현, 과대광고, 비교광고 패턴)으로 빠르게 필터링하고, 통과한 건에 대해 AI가 맥락을 분석하여 잠재적 위반 사항을 탐지합니다. 규칙 기반 검수가 70점 이상이면 PASS, 미만이면 AI 분석으로 넘어갑니다.
