2. 병원 등록 신청

현재 상태

관리자가 직접 등록admin_hospital_wizard.php (7단계) ✅
병원이 직접 신청❌ 미구현 — 마이페이지에서 신청 메뉴 필요

필요한 개발 (시나리오)

🔵 A. 마이페이지 "병원 등록 신청" 메뉴

mypage.php에 병원관계자(mb_1='hospital')만 보이는 "병원 등록 신청" 메뉴 추가.
관리 대시보드에서 이 메뉴 표시 여부를 ON/OFF 설정 가능 (gangnamunni_settings.show_hospital_apply_menu)

🔵 B. 병원 등록 신청 폼 (hospital_apply.php)

병원관계자 로그인 상태에서 접근. 입력: 병원명/주소/전화/영업시간/카테고리/사업자등록증 업로드.
제출 시 gangnamunni_hospitals에 status='pending'으로 INSERT + 관리자에게 알림 이메일

🔵 C. 관리자 설정 (admin_ad_settings.php 또는 별도)

"병원 등록 신청 메뉴 표시" 토글 → show_hospital_apply_menu = 1/0
"신청 시 필수 서류" 설정 (사업자등록증/의료기관면허 등)

3. 관리자 승인/반려

페이지admin_hospitals.php ✅
대기 목록status='pending' 필터 → 신청 내역 확인
승인is_active=1, reviewed_by, reviewed_at 기록
반려반려 사유 저장

승인 시 자동 처리 (시나리오)

🔵 D. 승인 시 hospital_admin 계정 자동 생성

admin_hospitals.php에서 "승인" 클릭 시:
① gangnamunni_admins에 hospital_admin 계정 INSERT (아이디: 병원 이메일, 비밀번호: 자동 생성)
② 병원 이메일로 승인 알림 + 관리자 로그인 정보 발송
③ ad_grade 기본값 'none' (Free) 배정

🔵 E. 반려 시 이메일 통보

반려 사유와 함께 병원 이메일로 알림 발송 + 재신청 안내

9. 추가 개발 시나리오

🔴 A. 마이페이지 "병원 등록 신청" 메뉴 (신규)

파일: mypage.php 수정 + hospital_apply.php 신규
조건: g5_member.mb_1 = 'hospital' 인 경우만 표시
관리 설정: gangnamunni_settings.show_hospital_apply_menu = 1/0 (admin_ad_settings.php에서 토글)
신청 폼: 병원명/주소/전화/카테고리/영업시간/사업자등록증/대표자명
제출 시: gangnamunni_hospitals INSERT (status=pending) + 관리자 이메일 알림

🔴 B. 승인 시 hospital_admin 자동 생성 + 이메일

파일: admin_hospitals.php 승인 로직 수정
자동 처리:
① gangnamunni_admins INSERT (role=hospital_admin, hospital_id=병원ID)
② 임시 비밀번호 생성 (6자리 랜덤)
③ mailer()로 승인 + 로그인 정보 이메일 발송
④ ad_grade = 'none' (Free) 기본 배정

🔴 C. 반려 시 이메일 통보

파일: admin_hospitals.php 반려 로직 수정
자동 처리: 반려 사유 + 재신청 방법 안내 이메일 발송

🟡 D. 병원 관리자 전용 대시보드 커스터마이징

현재: hospital_admin 로그인 시 사이드바에서 18키만 표시 (RBAC)
추가: 관리 대시보드에서 병원 관리자에게 보일 메뉴를 개별 ON/OFF
파일: admin_admins.php에서 병원별 커스텀 permissions 편집

🟡 E. 예약/승인 이메일 알림

현재: 예약 접수 시 알림 없음
추가: booking.php에서 예약 저장 후 mailer()로 병원 + 사용자에게 확인 이메일

🟢 F. CPV 결제 연동

partner_wallet.php 충전 → PG 결제 (이니시스/KCP) 연동

🟢 G. 시술 승인 워크플로우

병원이 시술 등록 → pending → 관리자 승인 → active
