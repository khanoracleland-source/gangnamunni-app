크론 동기화 시스템

1분 간격으로 4단계 동기화가 자동 실행됩니다. */1 * * * * cron_sync.sh

1단계 HMS -> 서울미녀

파일: sync_hms_to_gangnamunni.php

  • 병원 정보 동기화
  • 의사 정보 동기화
  • 진료과 목록 동기화
2단계 서울미녀 -> HMS

파일: sync_gangnamunni_to_hms.php

  • 상담 요청 동기화
  • 예약 정보 동기화
3단계 회원 양방향 동기화

파일: sync_members.php

  • Gnuboard <-> HMS 회원 동기화
  • member_sync 매핑 테이블 관리
  • bcrypt 해시 직접 복사
4단계 카테고리 양방향 동기화

파일: sync_hospital_type.php

  • hospital_type <-> gangnamunni_categories
  • 12건 시술 카테고리 매핑

SSO 통합 로그인

3개 시스템(HMS, Gnuboard, 서울미녀) 간 단일 로그인(SSO)을 지원합니다.

SSO 흐름
  1. 로그인 발생: 사용자가 어느 시스템이든 로그인하면 SSO 토큰이 발급됩니다.
  2. 토큰 저장: sso_tokens DB 테이블에 토큰 저장, sb_sso_token 쿠키로 공유 (24시간 유효)
  3. 자동 로그인: 다른 시스템 방문 시 쿠키의 SSO 토큰으로 자동 인증 처리
  4. 로그아웃: 어느 시스템에서든 로그아웃하면 SSO 토큰 삭제, 전체 로그아웃
시스템별 구현
시스템세션명구현 파일
HMS (Laravel)hms_saas_sessionSsoBridge 미들웨어, SsoLoginListener, SsoLogoutListener
GnuboardG5PHPSESSIDextend/hms_sync.extend.php, extend/sso_auto_login.extend.php
서울미녀PHPSESSIDdashboard.php (SSO 자동 로그인 + 토큰 발급)
주의: Laravel의 EncryptCookies에서 sb_sso_token을 암호화 제외 처리해야 PHP와 Laravel 간 쿠키 공유가 가능합니다.
