개요

등록 마법사는 HMS(병원 관리 시스템)의 데이터 등록을 단계별로 안내하는 위저드 UI입니다. 모든 마법사는 동일한 구조로 구현되어 일관된 사용자 경험을 제공합니다.

공통 특징
  • 단계별 진행 표시 (프로그레스 바 + 단계 인디케이터)
  • 실시간 필드 유효성 검사 (입력 즉시 피드백)
  • 이전/다음 단계 탐색 (데이터 유지)
  • 최종 확인 화면에서 전체 입력 내용 검토
  • AJAX 기반 비동기 저장 (페이지 새로고침 없음)
  • 엑셀 Import 대량 등록 지원

01 의사 등록 마법사

파일: admin_doctor_wizard.php

의사 등록 마법사 화면 (admin_doctor_wizard.php)
단계별 진행
  1. 기본 정보
    필드타입필수검증 규칙
    이름 (한글)textO2~20자, 한글만
    이름 (영문)textO2~50자, 영문만
    성별selectO남/여
    생년월일dateO과거 날짜
    이메일emailO이메일 형식, 중복 확인
    전화번호telO010-XXXX-XXXX 형식
  2. 전문 정보
    진료과 선택 (다중), 전문의 자격증 번호, 면허 번호, 경력 (년), 소속 병원 선택
  3. 프로필
    프로필 사진 업로드 (JPG/PNG, 최대 5MB), 자기소개, 주요 시술 태그
  4. 스케줄 설정
    요일별 진료 시간, 점심 시간, 휴진일 설정
  5. 확인 및 저장
    전체 입력 내용 요약 표시, 수정 필요 시 해당 단계로 이동, 저장 버튼

04 환자 등록 마법사

파일: admin_patient_wizard.php

  1. 기본 정보: 이름, 성별, 생년월일, 연락처, 이메일, 주소
  2. 의료 정보: 혈액형, 알레르기, 기저 질환, 복용 중인 약물
  3. 보험 정보: 보험 유형, 보험 번호, 보험사
  4. 보호자 정보: 보호자 이름, 관계, 연락처 (선택사항)
  5. 확인 및 저장: 전체 내용 검토 후 저장
개인정보 주의: 환자 의료 정보는 민감 정보로 분류됩니다. 저장 시 암호화되며, 접근 로그가 자동으로 기록됩니다.

06 약품 등록 마법사

파일: admin_medicine_wizard.php

  1. 기본 정보: 약품명 (한글/영문), 분류 (전문의약품/일반의약품), 제조사
  2. 상세 정보: 성분, 함량, 제형 (정제/캡슐/주사 등), 보관 조건

  4. 확인 및 저장: 전체 내용 검토 후 저장
팁: 약품 데이터는 엑셀 Import로 대량 등록하는 것이 효율적입니다. 템플릿 다운로드 후 데이터를 입력하세요.

07 예약 등록 마법사

파일: admin_appointment_wizard.php

  1. 환자 선택: 기존 환자 검색/선택 또는 신규 환자 즉시 등록
  2. 의사/진료과 선택: 진료과 -> 담당 의사 연동 선택
  3. 일정 선택: 달력 UI로 날짜 선택 -> 가능한 시간대 표시 -> 시간 선택
  4. 추가 정보: 예약 유형 (초진/재진), 증상 메모, 특이사항
  5. 확인 및 저장: 예약 요약 표시, 문자/이메일 알림 발송 옵션

엑셀 Import/Export

모든 등록 마법사는 엑셀 기반 대량 데이터 Import 및 Export를 지원합니다.

Import 절차
  1. 템플릿 다운로드: 해당 마법사 페이지에서 "엑셀 템플릿 다운로드" 버튼 클릭
  2. 데이터 입력: 템플릿의 각 컬럼에 맞게 데이터 입력 (헤더 행 유지)
  3. 파일 업로드: "엑셀 Import" 버튼 -> 파일 선택 -> 업로드
  4. 유효성 검사: 서버에서 각 행의 데이터 유효성 자동 검사
  5. 결과 확인: 성공/실패 건수 표시, 실패 건은 오류 메시지와 함께 다운로드 가능
Export 기능
기능설명
전체 Export현재 데이터 전체를 엑셀 파일로 다운로드
필터 Export현재 검색/필터 조건에 맞는 데이터만 Export
선택 Export체크박스로 선택한 항목만 Export
템플릿 Export빈 템플릿 파일 다운로드 (Import용)
지원 파일 형식
.xlsx (Excel 2007+) .xls (Excel 97-2003) .csv (쉼표 구분)
제한사항: 한 번에 최대 1,000건까지 Import 가능합니다. 대용량 데이터는 여러 번 나누어 Import하세요.
