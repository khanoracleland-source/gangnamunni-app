Hospital Admin RBAC 기반

병원 관리자 가이드

서울미녀 플랫폼에서 병원 관리자(hospital_admin)와 병원 부관리자(hospital_sub_admin)의 권한, 접근 메뉴, 기능을 안내합니다.

01 역할 체계 (RBAC)

서울미녀 플랫폼은 6단계 역할 기반 접근 제어(RBAC)를 사용합니다.

역할라벨권한 수병원 제한설명
super_admin최고관리자전체 (*)없음모든 기능 접근
admin관리자50+없음대부분 기능 접근 (시스템 설정 제외)
editor에디터23+없음콘텐츠 관리 중심
hospital_admin병원관리자18자기 병원만병원 운영 + 시술 + 지출 관리
hospital_sub_admin병원부관리자6자기 병원만기본 조회 + 예약 관리
viewer뷰어1없음대시보드만 조회

04 프론트엔드 관리자 바 (이윰빌더 스타일)

관리자가 프론트엔드(사용자 페이지)를 볼 때 상단에 관리자 바가 표시됩니다.

최고관리자 (super_admin):
Admin | 대시보드 광고설정 테마 디자인토큰 병원 시술 이벤트 | 디자인모드 디스플레이
병원관리자 (hospital_admin):
병원 Admin | 대시보드 시술관리 지출/월렛 설정 AI설정 (서울미녀 강남점)

각 섹션에 마우스를 올리면 편집 버튼이 나타나며, 클릭하면 해당 관리 페이지가 새 탭으로 열립니다. 병원관리자는 자기 병원 관련 편집 버튼만 표시됩니다.

06 병원 지출 대시보드 (partner_wallet.php)

병원관리자가 자기 병원의 CPV(Cost Per View) 광고비, AI 사용료 등 지출 현황을 확인하는 페이지입니다.

서울미녀 강남점 월렛
₩ 1,250,000
충전: ₩2,000,000 사용: ₩750,000
주요 기능
  • 잔액 확인: 현재 CPV 월렛 잔액 실시간 표시
  • 거래 내역: 충전/차감/환불 이력 (날짜, 금액, 사유)
  • 지출 통계: 일별/월별 광고비 + AI 사용료 차트
  • 예산 한도: 일일 캡 설정으로 과다 지출 방지
  • AI 비용: AI 리뷰 분석, 이미지 생성 등 AI 사용 비용 확인
CPV 과금 테이블: gangnamunni_cpv_wallets (잔액), gangnamunni_cpv_transactions (거래), gangnamunni_cpv_logs (로그), gangnamunni_cpv_daily_stats (일별 통계)

07 보안 정책

  • 데이터 격리: 병원관리자는 hospital_id 세션 값으로 자기 병원 데이터만 조회/수정 가능
  • SQL 격리: 모든 쿼리에 WHERE hospital_id = ? 조건 적용
  • 세션 변수: $_SESSION['ad_admin_hospital_id'], $_SESSION['partner_hospital_id']
  • 메뉴 필터링: check_permission()으로 허용된 메뉴만 사이드바에 표시
  • 프론트엔드: 인라인 편집 버튼도 역할별 필터링 (병원 관련 버튼만 표시)
  • 비밀번호: password_hash() / password_verify() (bcrypt)
