1. 수정요청 버튼 위치

매뉴얼 페이지 내 2가지 위치에 수정요청 버튼이 있습니다.

A

페이지 상단 — 전체 수정요청

페이지 오른쪽 상단에 있는 빨간 버튼입니다. 해당 페이지 전체에 대한 피드백을 남길 때 사용합니다.

 
B

섹션 제목 옆 — 해당 항목 수정요청

각 소제목(h4) 오른쪽에 있는 작은 버튼입니다. 특정 항목만 수정을 요청할 때 더 정확하게 위치를 전달할 수 있습니다.

2. 팝업 사용법

수정요청 버튼을 클릭하면 아래와 같은 팝업이 나타납니다.

2. 예약관리 메뉴가 클릭해도 이동이 안 됩니다. 화면 캡처를 첨부합니다.
③ 첨부 이미지 (선택)
이미지를 드래그하거나, 클릭해서 파일을 선택하세요
또는 Ctrl+V로 클립보드 이미지 붙여넣기
헤더를 드래그하여 팝업 위치를 이동할 수 있습니다
1

위치 정보 — 자동 입력됨

버튼을 클릭한 위치(파일명, 탭, 섹션)가 자동으로 채워집니다. 수정하지 않아도 됩니다.

2

요청 제목 입력 (필수)

무엇이 문제인지 한 줄로 요약해서 입력합니다.
예: "병원 목록 이미지가 깨져서 보입니다"

3

요청 내용 입력 (필수)

어떤 상황인지, 어떻게 수정해야 하는지 상세히 적어주세요.
재현 방법, 발생 조건 등을 포함하면 더 빠르게 처리됩니다.

4

이미지 첨부 (선택)

문제 화면을 캡처하여 첨부하면 개발팀이 더 정확히 파악할 수 있습니다.
여러 장 첨부 가능합니다.

팝업은 드래그로 화면 어디든 이동할 수 있습니다. 매뉴얼을 보면서 내용을 작성하고 싶을 때 편리합니다.
3. 이미지 첨부 3가지 방법
파일 직접 선택

이미지 업로드 영역을 클릭하면 파일 탐색기가 열립니다. PNG, JPG, GIF 지원.

클립보드 붙여넣기

화면 캡처 후 Ctrl+V 또는 클립보드 붙여넣기 버튼을 클릭합니다.

드래그 앤 드롭

이미지 파일을 업로드 영역으로 드래그해서 놓으면 자동으로 첨부됩니다.

빠른 캡처 방법:
Windows: Win+Shift+S → 영역 선택 → 팝업에서 Ctrl+V
Mac: ⌘+Shift+4 → 영역 선택 → 팝업에서 ⌘V
팝업이 열릴 때 현재 화면 아래에 있는 이미지가 자동으로 감지되어 첨부될 수 있습니다.
불필요하면 이미지 초기화 버튼으로 삭제하세요.
4. 제출 후 관리자 화면에서 확인

수정요청 제출 버튼을 누르면 즉시 관리자 화면에 반영됩니다.

5. 자주 묻는 질문

제출 즉시 관리자 목록에 등록됩니다. 처리 시간은 내용에 따라 다르며, 완료 시 상태가 완료로 변경됩니다.

네, 여러 장 첨부 가능합니다. 파일 선택 시 다중 선택하거나, 클립보드 붙여넣기를 반복하면 됩니다.

네. 팝업 상단 헤더 부분을 마우스로 드래그하면 화면 어디든 이동할 수 있습니다. 매뉴얼을 보면서 내용을 동시에 입력할 때 유용합니다.

관리자 상세 페이지에서 요청 제목, 내용, 위치 정보를 직접 수정하고 저장할 수 있습니다.
