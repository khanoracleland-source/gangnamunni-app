01 개요

서울미녀 플랫폼은 멀티 산업 SaaS로 설계되어, 하나의 코드베이스로 다양한 업종의 서비스를 운영할 수 있습니다.

항목설명
핵심 모듈includes/industry_terms.php — IndustryPreset 싱글톤 클래스
프리셋 위치includes/presets/*.json (10개 파일)
관리자 UIadmin_industry.php — 업종 선택 + 용어 미리보기 + 도메인 설정
용어 함수term('business') → "병원"(의료) / "사무소"(법률) / "학원"(교육)
사이트명site_name() → DB theme_settings.site_name 우선
도메인 상수SITE_DOMAIN, SITE_BASE_PATH, SITE_FULL_URL

04 업종 전환 방법

관리자 대시보드에서 전환
Step 1: admin_industry.php 접속
↓
Step 2: 업종 카드 클릭 → 용어/카테고리 미리보기 확인
↓
Step 3: 카드 더블클릭 → 확인 팝업 → 업종 변경 적용
↓
Step 4: 용어, 카테고리, 테마 색상 자동 변경 완료
도메인/브랜딩 변경

같은 페이지 하단의 "브랜딩·도메인 설정" 섹션에서:

도메인site_domainhms.seoulbeauty.app → 새 도메인
URL 경로site_base_path/hairwang/gangnamunni/ → 새 경로
앱 이름app_name서울미녀 → 새 브랜드명
패키지 IDapp_package_idcom.celebhospital.patient → 새 ID
도메인 변경 후 Apache vhost + SSL(Cloudflare/Let's Encrypt) 설정이 필요합니다.

05 앱 브랜드 변경

Android — brand.properties
APP_NAME=서울미녀 ← 앱 표시 이름
APP_ID=com.celebhospital.patient ← 패키지 ID
BASE_URL=https://... ← 서버 URL
FCM_TOPIC=seoulbeauty_all ← 알림 토픽
KEY_ALIAS=celebhospital... ← 서명 키

수정 후 ./gradlew assembleRelease → APK/AAB 생성

iOS — brand_config.json
{
  "app_name": "서울미녀",
  "bundle_id": "com.celebhospital.patient",
  "base_url": "https://...",
  "primary_color": "#AE1932"
}

수정 후 Xcode Archive → IPA 생성

아이콘 자동 생성
python generate_icons.py new_icon_1024.png

→ Android: mipmap-mdpi~xxxhdpi (5밀도 × 3파일 = 15개)
→ iOS: AppIcon.appiconset (12개 사이즈)
→ Splash: 480x480 자동 생성
