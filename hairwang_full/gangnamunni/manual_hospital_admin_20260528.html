2 신규 병원 관리자 계정 발급 절차

  1. 총 관리자(admin)로 로그인
  2. 좌측 사이드바 → 관리자 관리 → admin_admins.php 진입
  3. 우측 상단 "+ 신규 관리자 추가" 클릭
  4. 다음 정보 입력:
    • 로그인 ID : 영문 + 숫자 (예: hospital_xxx)
    • 비밀번호 : 8자 이상
    • 역할 선택 : hospital_admin 또는 hospital_sub_admin
    • 병원 매핑 : 해당 병원 ID 선택 (필수, 자기 병원만 접근 가능)
    • tenant_id : 병원 그룹 ID (선택)
  5. 저장 → 즉시 발급 완료

3 병원 관리자 접속 방법

  1. 웹 브라우저에서 관리자 페이지 접속
  2. 발급된 ID/비밀번호로 로그인
  3. 대시보드에서 자기 병원 관련 메뉴만 표시됨 (자동 필터링)
  4. 주요 접근 가능 메뉴:
    • 병원 정보 수정 (자기 병원만)
    • 의사/이벤트/시술 관리 (자기 병원만)
    • 예약 관리 (자기 병원 예약만)
    • 후기 답글 (자기 병원 후기만)
    • 광고 관리 (자기 병원 광고만)

4 병원 부관리자 (hospital_sub_admin)

병원 관리자가 자기 병원의 부관리자를 직접 발급할 수 있습니다.

  1. 병원 관리자로 로그인
  2. 좌측 사이드바 → 병원 관리 → 부관리자 관리
  3. "+ 부관리자 추가" 클릭 → ID/PW 입력 → 9개 메뉴 키 중 권한 선택 → 저장

5 계정 정지/복구

  • 총 관리자 → admin_admins.php → 해당 계정의 "정지" 버튼 클릭
  • 정지된 계정은 로그인 시도 시 차단
  • "복구" 버튼으로 즉시 재활성화 가능

6 비밀번호 재설정 (관리자가 회원 비밀번호 변경)

  1. 총 관리자 → admin_members.php → 해당 회원 행 → "비밀번호 초기화" 클릭
  2. 시스템이 8자리 임시 비밀번호 자동 생성 + 화면에 표시
  3. 해당 임시 비밀번호를 회원에게 전달
  4. 회원은 로그인 후 마이페이지에서 새 비밀번호로 변경
