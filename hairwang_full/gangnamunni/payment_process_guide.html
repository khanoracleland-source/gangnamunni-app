Part A: PG 결제 시스템 (영카트 이니시스)

이 시스템은 무엇인가요?
서울미녀에서 광고 상품이나 병원 등록 상품을 실제 결제(카드/무통장)할 수 있는 시스템입니다.
영카트(Gnuboard 쇼핑몰)와 이니시스 PG를 연동하여, 관리자가 상품을 등록하고 결제를 처리합니다.
현재는 테스트 모드(INIpayTest)로 실제 결제가 발생하지 않습니다.
A1
결제 현황 대시보드
admin_payment.php
무엇을 보는 화면인가요?
이 페이지는 모든 결제 주문 목록을 한눈에 볼 수 있는 메인 화면입니다. 고객이 결제한 모든 주문이 여기에 나타나며, 주문번호, 결제일, 금액, 상태(완료/대기/취소)를 확인할 수 있습니다.
어떻게 접근하나요?
1 관리자로 로그인 (admin / admin123)
2 왼쪽 사이드바 → "결제 관리" 그룹 클릭
3 "결제 현황" 메뉴 클릭
알아두세요
  • 주문 상태: 완료(녹색) = 결제 성공, 대기(노란색) = 입금 대기, 취소(빨간색) = 취소됨
  • 검색 필터로 날짜, 상태, 상품별 필터링 가능
  • 테스트 MID(INIpayTest)에서는 실제 돈이 빠지지 않습니다
A2
상품 관리
admin_payment.php?tab=products
무엇을 보는 화면인가요?
결제할 수 있는 상품 6종을 관리하는 화면입니다. 각 상품의 이름, 가격, 카테고리를 확인하고 수정할 수 있습니다.
등록된 상품 목록:
상품명가격카테고리
배너 광고 1개월110,000원광고
프리미엄 광고 1개월330,000원광고
인피드 광고 1개월220,000원광고
병원 기본 등록550,000원병원
병원 프리미엄 등록1,100,000원병원
병원 월정액 구독99,000원구독
A3
매출 통계
admin_payment.php?tab=stats
무엇을 보는 화면인가요?
월별 매출 현황을 차트와 표로 보여줍니다. 얼마나 결제가 이루어졌는지, 어떤 상품이 인기 있는지 한눈에 파악할 수 있습니다.
A4
PG 설정
admin_payment.php?tab=pg_settings
무엇을 보는 화면인가요?
PG(Payment Gateway) 설정을 관리하는 화면입니다. 어떤 결제사(이니시스, 카카오페이 등)를 사용할지, 테스트 모드인지 실결제 모드인지 설정합니다.
주요 설정 항목:
1 PG사 선택: 현재 이니시스(inicis) 사용
2 MID (가맹점 ID): INIpayTest (테스트용, 실결제 없음)
3 결제 수단: 카드 결제 ON, 무통장 입금 ON
4 테스트 모드: ON (실제 돈이 빠지지 않음)
중요!
  • INIpayTest는 이니시스 공식 테스트 MID입니다. 실제 돈이 결제되지 않습니다.
  • 실서비스 전환 시 실제 MID로 교체하고 테스트 모드를 OFF로 변경해야 합니다.
  • 지원 PG: 이니시스, KCP, 카카오페이, NICEpay, LG U+, 네이버페이 (6개)
A5
테스트 결제 페이지
admin_pay_bridge.php
무엇을 하는 화면인가요?
실제로 테스트 결제를 진행할 수 있는 페이지입니다. 상품을 선택하고, 결제 방법(카드/무통장)을 선택하면 이니시스 결제창이 뜹니다.
결제 진행 순서:
1 카테고리 선택 (광고 상품 / 병원 등록 / 구독 상품)
2 원하는 상품을 클릭하여 선택
3 결제 방법 선택 (신용카드 또는 무통장 입금)
4 "결제하기" 버튼 클릭
5 이니시스 결제창이 열리면 가상 카드번호로 승인
6 결제 완료 → "결제 현황"에서 확인

Part B: CPV 지갑 시스템

CPV 지갑이란?
병원이 선불 충전하면, 환자가 해당 병원 페이지를 볼 때마다 자동으로 조금씩 차감되는 시스템입니다.
네이버 검색광고의 CPC(클릭당 과금)와 비슷하지만, 여기서는 CPV(조회당 과금)입니다.
현재 Master Switch OFF 상태이므로 실제 과금은 발생하지 않습니다.
B1
지갑 관리 (관리자 화면)
admin_wallet.php
무엇을 보는 화면인가요?
모든 병원의 지갑(잔액)을 한눈에 관리하는 화면입니다.
상단에 전체 잔액 합계, 오늘 충전액, 오늘 소진액 등의 요약 카드가 있고,
아래에 병원별 잔액, 상태(활성/일시정지), 마지막 거래일이 표시됩니다.
관리자가 할 수 있는 작업:
1 충전: 병원 지갑에 금액을 넣어줌 (PG 결제 확인 후)
2 조정: 잘못된 금액 수정 (+ 또는 - 가능, 사유 필수)
3 거래 내역 보기: 각 병원의 충전/차감/환불 이력 확인
B2
충전 모달 (팝업)
admin_wallet.php → [충전] 버튼 클릭
어떤 화면인가요?
병원 지갑에 수동으로 금액을 충전하는 팝업 창입니다.
PG 결제 확인 후 관리자가 직접 충전 처리할 때 사용합니다.
입력 항목:
1 충전 금액: 실제 충전할 금액 (원 단위)
2 보너스 금액: 추가 서비스 금액 (선택)
3 설명: 충전 사유 (예: "3월 광고비 입금 확인")
4 PG 주문번호: 결제와 연결할 주문번호 (선택)
안전장치
  • 모든 충전/조정은 거래 내역에 기록됩니다 (삭제 불가)
  • 잔액 변경 시 트랜잭션(DB Lock)으로 동시 접근 보호
  • 관리자 ID가 자동으로 기록됩니다
B3
CPV 통합 설정 (충전 상품 가격)
admin_cpv_settings.php
무엇을 설정하는 화면인가요?
CPV 과금 시스템의 모든 설정값(55개)을 한 곳에서 관리합니다.
마스터 스위치, 기본 단가, 충전 상품 가격, 가중치, 정산 설정 등이 6개 그룹으로 나뉘어 있습니다.
충전 상품 가격 예시:
상품가격보너스
라이트50,000원0원
베이직100,000원5,000원
스탠다드300,000원30,000원
프리미엄500,000원75,000원
비즈니스1,000,000원200,000원
엔터프라이즈3,000,000원900,000원
B4
파트너 지갑 (병원용 화면)
partner_wallet.php?hospital_id=8093
누가 보는 화면인가요?
병원 관리자(파트너)가 자기 병원의 지갑을 확인하는 화면입니다.
관리자 페이지와 별도의 독립된 페이지로, 모바일에서도 잘 보입니다.
화면 구성:
1 잔액 카드: 현재 잔액 + 총 충전액 + 총 소진액 + 일일 한도
2 충전 상품: 6가지 충전 상품 카드 (라이트~엔터프라이즈)
3 거래 내역: 최근 충전/차감/환불 이력
B5
파트너 예산 설정
partner_settings.php?hospital_id=8093
무엇을 설정하는 화면인가요?
병원이 하루에 최대 얼마까지 쓸 수 있는지 예산을 설정합니다. 잔액이 일정 금액 이하로 떨어지면 알림을 받을 수도 있습니다.
설정 항목:
1 일일 예산 한도: 하루 최대 차감 금액 (슬라이더로 조절)
2 잔액 알림 임계값: 이 금액 이하가 되면 알림 발송
3 과금 일시정지: ON 시 조회당 차감 중단
4 자동정지: 잔액 0원 시 자동으로 과금 정지

용어 사전

PG (Payment Gateway)
결제 대행 서비스. 카드사/은행과 직접 연동하지 않고, PG사(이니시스, KCP 등)를 통해 결제를 처리합니다. 쇼핑몰에서 카드 결제할 때 뜨는 결제창이 바로 PG입니다.
MID (Merchant ID)
PG사에서 발급받는 가맹점 고유 ID. INIpayTest는 이니시스 공식 테스트 MID로, 실제 결제가 이루어지지 않습니다.
CPV (Cost Per View)
조회당 과금. 방문자가 병원 페이지를 한 번 볼 때마다 병원 지갑에서 일정 금액이 차감됩니다. 네이버 CPC(클릭당 과금)와 유사한 개념입니다.
지갑 (Wallet)
병원별 선불 잔액. 충전 후 CPV 과금 시 자동 차감됩니다. 잔액이 0이 되면 과금이 자동 정지됩니다.
영카트 (Youngcart)
Gnuboard(그누보드) 기반 한국형 오픈소스 쇼핑몰. g5_shop_* 테이블을 사용하며, 이니시스 등 국내 PG 모듈을 기본 제공합니다.
정산 (Settlement)
월 단위로 병원별 CPV 사용량을 집계하여 청구하는 것. 공급가 + VAT(10%) = 합계 금액으로 계산됩니다.
가중치 (Weight)
CPV 단가를 높이거나 낮추는 배율. 예: 인기 키워드("쌍꺼풀")는 가중치 1.5배 → 기본 단가 300원이면 450원으로 과금.
Beacon API
브라우저가 서버에 비동기로 데이터를 보내는 기술. 페이지를 떠나는 순간에도 전송이 보장되어 CPV 추적에 사용됩니다.
