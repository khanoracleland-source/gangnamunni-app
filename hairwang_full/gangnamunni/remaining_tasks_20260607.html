🔵 디자인 협의/결정 필요 (3건)

현재 Figma 원본과 다르게 구현되어 있지만, 어느 쪽이 맞는지 클라이언트 사양 협의가 필요합니다.

1 메인페이지 — 카테고리 그리드 컬럼 수 우선순위 중
🎨 FIGMA 원본
4컬럼 그리드 (리프팅 / 써마지FLX / 텐써마 / 올리지오)
💻 현재 구현
3컬럼 그리드 + 가로 스크롤 (414px 화면폭 제약)
🛠 협의 옵션
  • A안: 4컬럼으로 변경 → 칩 텍스트 크기 축소 (글씨 작아져 가독성 ↓)
  • B안: 현재 3컬럼 유지 + 가로 스크롤 (Figma와 다르지만 가독성 우수)
  • C안: 더 큰 화면(태블릿/PC)만 4컬럼, 모바일은 3컬럼 (반응형)
💡 권장: C안 (반응형) — 모바일은 가독성 우선, 태블릿/PC만 Figma 매칭
2 메인페이지 — 이벤트 섹션 디자인 우선순위 중
🎨 FIGMA 원본
카드형 3개 가로 배치 (20% 할인 뱃지 + 시술명 + 가격)
💻 현재 구현
가로 banner 1개 ("친구 초대하면 10,000포인트!" 자동 회전)
🛠 협의 옵션
  • A안: Figma 카드형 3개로 변경 (이벤트 상세 데이터 추가 입력 필요)
  • B안: 현재 banner 유지 + Figma 카드형은 별도 섹션 추가 (둘 다)
  • C안: 현재 banner 유지 (admin 광고 설정으로 컨텐츠 변경 가능)
💡 권장: B안 (둘 다) — 친구 초대 banner + 이벤트 카드 섹션 별도 추가
3 메인페이지 — 상단 헤더 (글로벌 nav) 우선순위 낮
🎨 FIGMA 원본
서울미녀 로고 + "로그인 / 회원가입" 빨강 박스 버튼만 (단순)
💻 현재 구현 (로그인 상태)
서울미녀 로고 + "서울미녀… | 마이 | 로그아웃" 글로벌 nav 표시
🛠 협의 옵션
  • A안: 비로그인/로그인 상태별 표시 차이 (현재 구현 — Figma는 비로그인 상태 디자인)
  • B안: 로그인 상태에서도 단순하게 — "마이" 버튼 하나로 통일
  • C안: 현재 유지 (사용성 우수, Figma는 디자인 참고용)
💡 권장: A안 — 비로그인 상태에서 Figma처럼 단순 노출 확인 후 결정 (확률 높음, 이미 구현 가능성)
