③ 통합 HTML 리포트 자동 생성

Bootstrap 5.3.3
다크모드
시트 ID 매핑

기존 자동 매뉴얼 15종 시스템의 리포트 생성 로직을 응용. 항목별 카드 형식으로 다음 정보를 한 화면에 표시:

  • 시트 ID (1차 #N / 프론트 #N / 관리자 #N)
  • 수정 전/후 캡처 (썸네일 → 클릭 시 lightbox 확대)
  • 녹화 동영상 임베드 (해당 시)
  • 자동 테스트 결과 : ✓ PASS / ✗ FAIL / — SKIP
  • 처리 소요 시간 (ms 단위)
  • "직접 확인하기" 버튼 → 해당 실제 페이지 URL로 새 탭 열기
  • "이슈 보고" 버튼 → 검수자가 즉시 피드백 입력 (API → admin_fix_log)
