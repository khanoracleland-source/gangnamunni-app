# 백업 파일 저장 폴더
# 이 폴더에는 데이터베이스 백업 파일이 저장됩니다.

## 보안 경고

이 폴더는 외부에서 직접 접근할 수 없도록 보호되어야 합니다.

## 파일 형식

백업 파일은 다음 형식으로 저장됩니다:

[데이터베이스명]_backup_[YYYY-MM-DD]_[HH-MM-SS].sql

예시:
- carecraft_2025_backup_2026-01-19_12-00-00.sql
- frezka_backup_2026-01-19_12-01-00.sql
- hairwang_backup_2026-01-19_12-02-00.sql

## 저장 공간 관리

- 정기적으로 오래된 백업 파일을 삭제하세요.
- 백업 파일은 외부 저장소에도 보관하세요.
- 백업 파일의 크기에 따라 디스크 공간을 확인하세요.

## 백업 주기

- 매일 백업을 권장합니다.
- 중요한 변경사항 적용 전 백업을 권장합니다.
- 최소 주 1회 백업을 권장합니다.
