**추가된 함수**:

##### `increment_login_attempts($username)`
- 로그인 실패 시 카운트 증가
- 세션에 시도 횟수, 시각 기록
- 최대 횟수 초과 시 자동 잠금

##### `clear_login_attempts($username)`
- 로그인 성공 시 실패 횟수 초기화

##### `is_account_locked($username)`
- 계정 잠금 여부 확인
- 잠금 시간 경과 시 자동 해제

##### `get_lockout_remaining_time($username)`
- 잠금 남은 시간 계산 (초 단위)

##### `get_login_attempt_info($username)`
- 로그인 시도 정보 조회
- 남은 시도 횟수, 잠금 상태 등 반환

**`login()` 함수 수정**:
```php
function login($username, $password) {
    // Brute Force 방어: 계정 잠금 확인
    if (is_account_locked($username)) {
        $remaining_time = get_lockout_remaining_time($username);
        error_log("Login blocked - Account locked: $username");
        return false;
    }

    // 로그인 검증
    if ($username === ADMIN_USERNAME && password_verify($password, ADMIN_PASSWORD_HASH)) {
        clear_login_attempts($username);  // 성공 시 초기화
        // 세션 생성...
        return true;
    }

    increment_login_attempts($username);  // 실패 시 카운트 증가
    return false;
}
```

**`log_login_attempt()` 함수 개선**:
- 로그에 시도 횟수 기록
- 잠금 상태 표시
