## ⚠️ 발견된 문제 (이미 해결됨)

### 문제 상황
```
1. 비로그인 상태에서 앱 실행
2. FCM 토큰 받음 → LocalStorage 저장
3. g5_is_member = "" (빈 문자열)
4. 서버 전송 안함 ❌
5. 로그인 완료
6. 페이지는 그대로 → g5_is_member 여전히 ""
7. DOMContentLoaded 이미 발생 완료
8. 토큰 저장 안됨 ❌
```

### 근본 원인
1. **g5_is_member가 문자열로 정의됨**
   ```javascript
   const g5_is_member = "<?php echo $is_member; ?>"; // "1" 또는 ""
   ```

2. **페이지 이동 없이 로그인 시 변수 갱신 안됨**
   - 로그인 완료해도 `g5_is_member`는 페이지 로드 시점의 값 유지

3. **DOMContentLoaded는 한 번만 실행**
   - 로그인 후에는 재실행 안됨

## ✅ 최종 해결 방법

**[알림_기존_세팅분석및방법.md](알림_기존_세팅분석및방법.md)** 의 **Step 1** 코드 적용

### 핵심 해결책

1. **g5_member_id 변수 추가**
   ```php
   const g5_member_id = "<?php echo isset($member['mb_id'])?$member['mb_id']:''; ?>";
   ```

2. **앱 브리지 코드 추가**
   - Android/iOS 공통 `onTokenReceived()` 콜백
   - DOMContentLoaded에서 토큰 요청

3. **서버는 세션에서 mb_id 추출**
   ```php
   $mb_id = $member['mb_id']; // 세션 기반 (안전)
   ```

## 📊 여러 해결 방법 비교 (참고용)

아래는 개발 중 검토했던 여러 방법들입니다. 최종적으로 **방법 1 + API 방식**을 선택했습니다.

### 방법 1: 로그인 페이지에서 URL 파라미터 추가 ⭐⭐⭐⭐⭐

**장점**: 간단, 안정적
**단점**: 비회원 저장 불가

```php
// login_check.php 수정
$separator = strpos($link, '?') !== false ? '&' : '?';
$link_with_token_flag = $link . $separator . 'login_success=1';
goto_url($link_with_token_flag);
```

```javascript
// push_notification.js
document.addEventListener('DOMContentLoaded', function() {
    const urlParams = new URLSearchParams(window.location.search);
    const isLoginSuccess = urlParams.get('login_success') === '1';

    if(isLoginSuccess || g5_is_member) {
        const savedToken = localStorage.getItem('fcm_token');
        if(savedToken) {
            savePushTokenToGnuboard(savedToken);
        }
    }
});
```

---

### 방법 2: 비회원도 토큰 저장 허용 ⭐⭐⭐⭐

**장점**: 비로그인→로그인 자동 연결
**단점**: 서버 코드 수정 필요

```php
// ajax.push_token.php 수정
$mb_id = $member['mb_id'] ?? '';  // 비로그인 허용

$sql = "INSERT INTO g5_push_tokens
        SET mb_id = '{$mb_id}',
            pt_token = '{$token}',
            pt_platform = '{$platform}',
            pt_datetime = NOW()
        ON DUPLICATE KEY UPDATE
            mb_id = IF('{$mb_id}' != '', '{$mb_id}', mb_id),
            pt_datetime = NOW()";
```

---

### 방법 3: API 방식 사용 ⭐⭐⭐ (채택)

**장점**: 비회원 지원, CORS 설정 완료, 완성도 높음

```javascript
fetch(g5_url + '/api/push_token_save.php', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        fcm_token: token,
        user_id: g5_member_id || '',
        platform: platform,
        device_id: '',
        app_version: '1.0.0'
    })
});
```

---

### 방법 4: 이벤트 훅 활용 ⭐⭐

**장점**: 로그인 직후 즉시 실행
**단점**: 구현 복잡도 높음

```php
// extend/push_token_login.extend.php
add_event('member_login_check', 'set_token_save_flag', 10, 3);

function set_token_save_flag($mb, $link, $is_social_login) {
    set_session('need_fcm_token_save', '1');
}
```

## 🎯 최종 채택 방안

**조합**: 방법 1 (URL 파라미터) + 방법 3 (API 방식) + 앱 브리지

### 왜 이 조합인가?

1. **앱 브리지**
   - Android/iOS에서 토큰 요청
   - `onTokenReceived()` 콜백 통일

2. **API 방식**
   - 비회원도 저장 가능
   - 로그인 시 자동 mb_id 연결

3. **서버 세션 기반**
   - `$member['mb_id']` 사용
   - 클라이언트 조작 불가 (보안)
