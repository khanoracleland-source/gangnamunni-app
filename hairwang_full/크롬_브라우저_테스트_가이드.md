## 🔧 문제 해결

### 1. PHP를 찾을 수 없습니다

**오류 메시지**:
```
'php'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램, 또는 배치 파일이 아닙니다.
```

**해결 방법**:
1. PHP 설치 확인: `C:\php\php.exe`
2. 시스템 환경 변수 PATH에 PHP 경로 추가
3. CMD 재시작 후 `php -v` 실행

---

### 2. 데이터베이스 연결 실패

**오류 메시지**:
```
Connection failed: php_network_getaddresses: getaddrinfo failed
```

**해결 방법**:
1. MySQL 서버 실행 확인 (124.111.85.242:3306)
2. `dbconfig.php` 접속 정보 확인
3. 방화벽 설정 확인
4. `ping 124.111.85.242` 테스트

---

### 3. .env 파일을 찾을 수 없습니다

**오류 메시지**:
```
.env file not found: H:\...\new_http_v1_mars\.env
```

**해결 방법**:
1. `.env.example` 파일을 `.env`로 복사
2. 필요한 환경 변수 값 입력:
   ```ini
   FIREBASE_JSON_PATH=H:\path\to\firebase.json
   FIREBASE_PROJECT_ID=your-project-id
   ADMIN_PASSWORD_HASH=$2y$10$...
   ```

---

### 4. 포트가 이미 사용 중입니다

**오류 메시지**:
```
Failed to listen on localhost:8080 (reason: Address already in use)
```

**해결 방법**:
1. 다른 포트로 변경: `php -S localhost:8082`
2. 또는 기존 프로세스 종료:
   ```bash
   netstat -ano | findstr :8080
   taskkill /PID [프로세스ID] /F
   ```

---

### 5. Firebase JSON 파일을 찾을 수 없습니다

**오류 메시지**:
```
Firebase JSON file not found
```

**해결 방법**:
1. Firebase Console에서 서비스 계정 JSON 다운로드
2. `new_http_v1_mars/` 폴더에 복사
3. `.env` 파일에 경로 설정:
   ```ini
   FIREBASE_JSON_PATH=H:\carebaby_project\server_backup_dev\hairwang_dev_sns_shop_2026_01_18\new_http_v1_mars\firebase-key.json
   ```
