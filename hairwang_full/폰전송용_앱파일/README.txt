====================================================
헤어왕 SNS 자동 로그인 앱 - 폰 전송용 패키지
====================================================

📱 이 폴더에 포함된 파일:
====================================================

1. hairwang_android_sns.apk (7.3MB)
   → Android 폰에 직접 설치 가능한 APK 파일

2. api/ 폴더
   → 서버에 업로드할 PHP API 파일
   - api/sns/app_login.php
   - api/sns/app_callback.php
   - api/sns/token_to_session.php

3. js/ 폴더
   → 서버에 업로드할 JavaScript 파일
   - js/app_sns_login.js

4. 앱_전송_가이드.txt
   → 앱 설치 및 전송 방법 상세 가이드

5. sns_앱웨뷰개발_내역.md
   → 전체 개발 내역 및 기술 문서


====================================================
⚡ 빠른 시작 가이드
====================================================

Android 폰으로 앱 전송하기:
----------------------------------------------------
방법 1 (USB): adb install -r hairwang_android_sns.apk
방법 2 (이메일): APK 파일을 자신에게 이메일 전송 후 폰에서 다운로드
방법 3 (클라우드): 구글 드라이브에 업로드 후 폰에서 다운로드


iOS 앱은?
----------------------------------------------------
iOS는 Mac + Xcode가 필요합니다.
프로젝트 위치: hairwang_app_source/hairwang3/ios/mars/2.iOS/


서버 파일 업로드:
----------------------------------------------------
1) api/sns/ 폴더를 서버의 /api/sns/ 경로에 업로드
2) js/app_sns_login.js를 서버의 /js/ 경로에 업로드


====================================================
🎯 주요 기능
====================================================

✅ SNS 자동 로그인
   - 사용자가 이미 SNS에 로그인되어 있으면 원클릭 로그인
   - 시스템 브라우저 쿠키 공유 (Chrome/Safari)

✅ 지원 SNS (6개)
   - 네이버, 카카오, 구글, 페이스북, 트위터, 페이코

✅ 플랫폼별 최적화
   - Android: Chrome Custom Tabs
   - iOS: ASWebAuthenticationSession
   - 웹: OAuth 팝업
