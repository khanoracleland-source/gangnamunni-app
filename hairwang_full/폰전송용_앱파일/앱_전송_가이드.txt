📱 1. ANDROID APK 전송 방법
========================================

✅ APK 파일 위치:
   h:\carebaby_project\server_backup_dev\hairwang_dev_sns_shop_2026_01_18\hairwang_android_sns.apk
   (파일 크기: 7.3MB)

방법 1 - USB 케이블 (가장 빠름)
--------------------------------
1) 폰 설정 → 개발자 옵션 활성화
   - 설정 → 휴대전화 정보 → 빌드 번호 7번 탭

2) USB 디버깅 활성화
   - 설정 → 개발자 옵션 → USB 디버깅 ON

3) USB 연결 후 cmd 실행:
   adb install -r h:\carebaby_project\server_backup_dev\hairwang_dev_sns_shop_2026_01_18\hairwang_android_sns.apk

방법 2 - 파일 전송 (간편함)
--------------------------------
1) 이메일로 전송:
   - hairwang_android_sns.apk 파일을 자신의 이메일로 전송
   - 폰에서 이메일 확인 후 APK 다운로드

2) 클라우드 드라이브:
   - 구글 드라이브/원드라이브에 APK 업로드
   - 폰에서 드라이브 앱으로 다운로드

3) 폰에서 설치:
   - 다운로드한 APK 파일 탭
   - "알 수 없는 출처" 설치 허용 (최초 1회)
   - 설치 완료

방법 3 - 공유 폴더 (PC-폰 같은 네트워크)
--------------------------------
1) Windows 공유 폴더 설정
2) 폰에서 파일 관리자로 공유 폴더 접근
3) APK 다운로드 후 설치


========================================
🍎 2. iOS 앱 전송 방법
========================================

⚠️ iOS는 Mac + Xcode 필요!

Mac이 있는 경우:
--------------------------------
1) Mac으로 프로젝트 복사:
   hairwang_app_source/hairwang3/ios/mars/2.iOS/

2) Xcode에서 chamgosu.xcodeproj 열기

3) iPhone USB 연결

4) Xcode에서 실행 (▶ 버튼)
   - 자동으로 빌드 및 설치됨

5) iPhone 설정에서 신뢰:
   설정 → 일반 → VPN 및 기기 관리 → 개발자 앱 → 신뢰

Mac이 없는 경우:
--------------------------------
TestFlight 또는 App Store 정식 배포 필요
(Apple Developer 계정 $99/년 필요)


========================================
🌐 3. 웹 파일 업로드
========================================

서버로 업로드할 파일:
--------------------------------
1) api/sns/ 폴더 전체
   - app_login.php
   - app_callback.php
   - token_to_session.php

2) js/app_sns_login.js

업로드 방법:
--------------------------------
1) FTP/SFTP로 서버 접속

2) 파일 업로드:
   - api/sns/ → 서버의 /api/sns/
   - js/app_sns_login.js → 서버의 /js/

3) 파일 권한 설정 (필요시):
   chmod 644 api/sns/*.php
   chmod 644 js/app_sns_login.js
