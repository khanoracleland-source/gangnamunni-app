## 7. 보안 고려사항

### 7.1 현재 보안 현황

**문제점:**
- ⚠️ 모든 프로젝트가 `root` 계정을 사용하고 있음
- ⚠️ 비밀번호가 `.env` 및 `config.php` 파일에 평문으로 저장됨
- ⚠️ 데이터베이스 비밀번호가 이메일 형식(`<REMOVED_DB_PASSWORD>`)으로 취약함

### 7.2 권장 보안 개선 사항

1. **데이터베이스 계정 분리:**
   - 각 프로젝트별로 별도의 데이터베이스 사용자 계정 생성
   - 권한을 최소한으로 제한 (SELECT, INSERT, UPDATE, DELETE만 허용)

2. **비밀번호 강화:**
   - 강력한 비밀번호 사용 (최소 16자, 대소문자+숫자+특수문자 포함)
   - 정기적인 비밀번호 변경

3. **설정 파일 보호:**
   - `.env` 파일을 `.gitignore`에 추가하여 버전 관리 제외
   - `config.php` 파일의 비밀번호 부분을 별도 파일로 분리

4. **IP 기반 접근 제한:**
   - 데이터베이스 서버에서 특정 IP만 접근 허용하도록 방화벽 설정

5. **SSL/TLS 연결:**
   - 데이터베이스 연결에 SSL/TLS 사용 (MySQL 서버 설정 필요)
